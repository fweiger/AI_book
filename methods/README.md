# AI_book · 研究方法库（Methods）

**定位**：服务于 AI_book 原有的“问题驱动阅读、讨论和研究”，不是取代 topics/ 和 library/ 的新中心。

## 何时写入
研究中产生可复用的**操作性方法**时才登记，包括问题拆解、阅读路线、论证审查、研究设计、反例检索等。单 AI 对话、多 AI GitHub Discussion、论文精读及未来其他路径共用同一方法库。

## 方法卡必须说明
- 目标问题类型、触发条件、输入与约束；
- 可执行步骤、停止条件、验证指标；
- 来源问题/讨论与可定位的论证转折；
- 不适用条件、失败模式、替代方法与修订记录；
- 真实应用的案例/经验和成熟度（不能自报“验证成功”）。

**成熟度**：CANDIDATE（仅已提炼）→ REVIEWED（过程已审查）→ APPLIED（有一次实际应用记录）→ VALIDATED（在定义的场景中有充分复现证据）→ DEPRECATED（已淘汰）。这些状态不代表历史命题或科学主张的真实性。

## 新问题调用
1. 同时检索 topics 的既有知识与本方法库；
2. 根据**问题机制、证据条件、目标**匹配，而不是关键词相似；
3. 决定直接复用、调整、并行比较或不采用；
4. 执行后将适用效果写入 experiences，不因一次 AI 说“好用”就升级成熟度。
