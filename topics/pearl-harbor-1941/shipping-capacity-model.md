# TOPIC-004 · 1941年10月日本商船“可维持国力”预算审计

日期：2026-11-04；Q02/Q03/Q06；单位：**万总吨 Gross Register Tonnage（GRT）**，不是载油重吨、船舶载重吨或运输吞吐量。

## 来源与可核查输入

B-H09：日本防卫研究所相泽淳《开战时期的战争指导》，[公开原文印刷第136—137页](https://www.nids.mod.go.jp/publication/militaryhistory_research/mh_tokushu/eastasia_military_history/pdf/emh01_10.pdf)。引用《战史丛书》第5卷（开战经过）第211—224页，对1941年10月29—30日联络会议计划作解释。后者尚未逐页查原始表格。

| 指标 | 当时预算/设想（万总吨） |
|---|---:|
| 100总吨以上日本汽船总量 | 600 |
| 海军全战争期计划征用 | 180 |
| 陆军开战时计划征用 | 210 |
| 陆军开战后第8个月起计划征用 | 100 |
| 开战初始可留民用（600−180−210） | 210 |
| 第8个月起**尚未扣战损**的可留民用（600−180−100） | 320 |
| 军政部门认为持续维持经济所需民用吨位门槛 | 300 |
| 战争年度损失估计 | 80—100 |
| 年度新造船舶假设 | 60 |
| 在上述固定假设下全社会船队年度净缩减 | 20—40 |

## 不作伪造概率的会计式

- S(t+1) = S(t) + B(t) − L(t)；S为同口径船队总吨，B为实际造船加入，L为损失退出。
- Civilian(t) = S(t) − NavyRequisition(t) − ArmyRequisition(t)，**仅是分配上界**；实际还需维修停航、航程周转、港口与油轮占比。
- 当B=60、L∈[80,100]时，S每年净收缩20—40万总吨。**这只是1941年规划输入的条件演算，绝非战争实际历史序列。**

## 当时规划的结构性弱点

1. “第8个月民用320万总吨”是**没有扣除此前8个月战损**的账面上界；即便达到320，与持续维持经济所需300之间的余量也仅20万总吨。
2. 如果损失长期超过建造，全社会运力不断下降，民用运力可能不足目标。
3. 不能把100总吨以上汽船的GRT直接视作油轮载油吨，更不能据此给出荷印原油能运回日本的桶数。
4. “只攻荷印不攻美”的反事实，可能改变征用强度、受攻击概率、油田遭毁程度、周转时间。必须分情景，不可把已发生的全面战争损失复用为替代历史损失。

## 研究拓展（不补造样本）

对A外交、B只攻荷印、C同时攻菲律宾、D攻菲律宾+珍珠港四方案分别保留未知项：
- 油田实际恢复与产量F(t)；
- 可用油轮吨位与周转次数Tanker(t)，港口能力Port(t)；
- 美英荷敌对程度与潜艇有效损失函数L(t|scenario)；
- 长期本土可用燃料定义为上游油田产出、加工能力、运输能力三者共同制约的结果，不允许直接等于年产量。

## 需直接核对的原件

1. 1941年10月29—30日大本营政府联络会议物资预算原件；
2. 企画院鈴木貞一当时船舶征用与新造船假设；
3. 美国战略轰炸调查团日本船队与油运报告的GRT和deadweight混用问题；
4. 日本《战史丛书》南方石油、船舶损失篇的当时和战后数据。

结论：当前资料只支撑**条件性船队会计与策略脆弱性**，不支撑“珍珠港比只攻荷印更安全”的概率测算。
