## 评价维度（100分只评研究论证质量）

- **30**：来源可信、定位具体、原文读取深度标注诚实。
- **20**：还原1941不同部门的真实时间序列、政策权限、方案归属。
- **20**：主观概率与客观未知、反事实设计、替代解释及可证伪条件。
- **20**：石油产能、油轮实际运力与GRT/载重吨口径、时间尺度核算。
- **10**：有实质地处理对方最强证据，且对自己不利的事实未删除。

不设必须赢者；如果来源不够，输出 `INSUFFICIENT_EVIDENCE`，并列出哪份原档案最可能改变判断。需要区分“论证质量更高”与“历史上方案客观更优”，后者原则上很可能无法唯一识别。

## R2每个回应应包含

1. 对方`ROUND / SIDE / 评论URL / 被挑战的原句`
2. 本方承认其核心内容（steelman）
3. 反证或补充原文`来源名 / 形成日期 / 原文页码 / URL / 查阅状态`
4. 结论状态：`SUPPORTED / REFUTED / PARTIAL / UNDETERMINED`
5. 本方立场是否改变：`REVISE / WITHDRAW / MAINTAIN`
6. 下一步最能区分双方的史料或数量。

## R4裁判输出

- 两方各自成立所需的**前提集合**与最强有效证据；
- 相同来源在双方被引用的差异、是否“选择性阅读”；
- 关键 `C-ID` 的证据状态（不在讨论中自动更改正式文件）；
- “仅打荷印／打菲律宾但不打夏威夷／同时攻击珍珠港”之间真正的**方案边界**；
- 无法识别的 `p(美国主动军事干预 | 不攻击美国)`、时间尺度与成本；
- 评分可以记录，但**结论可为未决**；
- 需要新PR修改 `claims.md` 时标 `ACCEPTED_FOR_INTEGRATION`，**只有合并成功才标 `INTEGRATED`**。
