## 避免“多次引用同一史料=多次证实”

- 美国Exhibit17、Watson的官方史论述、NARA Butow等若都在引**同一1941-11-27联合备忘录**，只算一个原始政策观察。
- 美国Exhibit16和后出的CMH/NARA论述若都引**同一1941-11-05联合建议**，并不构成若干次独立批准。
- JACAR《杉山メモ》的官方解说、后出研究的引文与原档扫描是同一底层会议记录；但10月23日与10月27日是两个**不同形成日期**的会议，应保留各自定位。
- Ike1967英译与NIDS转引的1941铃木资源预算不能当作独立的两套实测数据；同样不把日本国立公文书馆对同一美军文书的另一个馆藏目录算作新决定。
- 双方AI报告内容互相引用及跨模型赞同均不是独立证据。

## 量纲规范（禁止误算）

- **GRT**：船舶总登记吨（容量/容积性计量口径），不是油轮**DWT**载重吨。
- **千升(kL)**：液体燃料体积；原油、炼成品、航空燃料须明确类别。
- **库存**是存量；第1/2/3年度预期新增供给是流量，不可直接相加为同年供给或把原油年产当净到港。Ike p.219中1.11m kL库存处于航空汽油段落、同页另有8.4m kL总液体燃料库存，应先确认燃料分类与计量截面，**不能把1.11m与8.4m直接相减或宣称矛盾**。
- Ike **p.216的27万GRT**仅是**海军征用油轮子项**，不能当日本油轮总DWT。
- Ike **pp.218—219**荷印第1/2/3年预计取得**30/200/450万kL**；全来源第1/2/3年新增预计**85/260/530万kL**；不是实际产量、装船或运抵日本。**840万kL与111万kL库存分类**未校日文底表，禁止不经核品类而加减。
- 约**600万GRT总船、390万征用、210万民用**是特定计划截面；民用动态低谷**160万GRT**属于另一时间段预测，不能当静态矛盾。

## 仍不可识别的最小因果链

美国对“仅袭英荷”实际军事决策：**联合参谋建议 → 总统/政治机关采纳 → 交战规则/舰队指令 → 战区执行**，目前仅第一环得到充分展示。

日本对B的实际可行性：**议程提出 → 机构决策及批准 → 油井与炼厂修复 → 油港装船 → 专用油轮DWT及航次 → 护航/绕行/损失 → 日本净到港**，目前仅第一环及A2情景下的部分经济计划得到展示。

**不得因为“史料有入口”将后续缺环标为已证。**
