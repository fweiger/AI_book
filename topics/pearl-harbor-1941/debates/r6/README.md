## R6 审核的严谨区分

- **史实**：1941年确有文书、会议讨论、军事计划或当事者预算；只按证据支持的最小措辞记录。
- **主观认知**：日本某机构担忧美国/菲律宾威胁，并不代表威胁会在B情景真实实现。
- **情景机制**：假定“美方早参战且菲基地被有效压制”，A1可能有局部军事优势；这不是对净供油或总体策略的推断。
- **不可识别变量**：美方在仅侵英荷时是否及何时参战、船油与港口净产出、A2相对A1边际军事/政治效用、三案36个月终战能力，全部保持 UNKNOWN。
- **伦理边界**：历史战争风险比较不构成对日本侵略政策的合法性或道德正当化。
