## 根本问题

1941年日本高层究竟为何认为先发制人打击美国，比只攻击英荷殖民地、继续谈判或收缩政策更可接受？这种判断在当时是理性风险管理、误判，还是陆海军制度性博弈的产物？

**核心区分**：
1. 真实的资源约束、军事部署与历史决策（可由档案检验）。
2. 1941年决策者主观相信的风险（要按发言者、日期和文件追踪）。
3. 美国在不同反事实情境中的实际行为（无法仅从日本的担忧推断）。
4. 评价“低风险”所需的概率、损失期限与效用函数（目前未知）。

本专题不将战略解释等同于侵略正当性；也不将“相对风险较小”混淆为“整体胜算高”。
