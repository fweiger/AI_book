## 0. 本轮需要解决的原问题及判定结果

原 Goal 是“哲学是什么、是否具有跨文明共同本质、无排他性定义时如何辨认与评价”。本轮不新增学派或独立项目，而是检查两个会直接影响答案的漏洞：

1. **共同性、必要性、充分性、排他性不是一回事**。现有边界案例说明共享问题与方法，却没有直接证明不存在共同本质。
2. **E1/E2/E3 并非天然同层三选一**。E1/E2 较直接讨论概念结构；E3 的弱版本解释历史语境，可能与两者兼容；只有 E3 的强历史构成论才可能在哲学身份上与别的理论竞争。

裁定：上述两点的方法修正 `PASS_FOR_LOGICAL_SCOPE`；以六案例检验 H2 的**独立分类能力**为 `NOT_ESTABLISHED`，不得报告“六例分类准确率”或将主答卷升格为终极定义。

## 1. 四个必须分别审查的逻辑命题

令 `P(x)`＝“明确选定粒度的活动 x 具有哲学身份”，`R(x)`＝“x 进行根本性/二阶反思”，`S(x)`＝“x 属于另一领域（例如科学）”。分类对象必须事先固定为**一项局部活动**，不可在一个推理中由局部段落换成整本著作或整个研究者。

| 命题 | 形式或问题 | 成立/失败所需证据 |
| --- | --- | --- |
| 共同属性/候选必要条件 | `∀x[P(x)→R(x)]` | 反例须 `P(a)∧¬R(a)`；其他领域也有 R 不构成反例 |
| 候选充分条件 | `∀x[R(x)→P(x)]` | 反例须 `R(a)∧¬P(a)`；若 x 可同时属哲学与科学则反例不成立 |
| 排他性领域划界 | 给出独占归属规则，并另行论证 `P` 与 `S` 是否互斥 | `R(a)∧S(a)` 不推出 `¬P(a)`；兼属本身可能合理 |
| “本质”究竟是什么 | 强充要定义、弱共同结构、规范性理想还是历史生成条件？ | 不能预设任何本质都必须给出对全部边界案例一刀切的排他算法 |

**结论 L01**：`R∧S` 只能支持“R 也见于 S”，不能反驳 R 对 P 的必要性；同理，尚未找到充要条件也不能证明此条件不可能存在。若要使 E1 受到真正挑战，先固定“共同本质”的强弱版本再检验。

## 2. E1/E2/E3 改成两层分析，不删除历史争论

### 第一层：概念结构与规范性辨认

- **E1 本质候选**：哲学是否具有跨案例的必要共同结构？强版追求充分必要条件，弱版可能只提供共同结构或规范理想；“不排他”仅打击强划界版本，不自动推翻弱版。
- **E2 家族相似候选**：通过有出处的典型、重叠和边缘案例理解“哲学”，但必须限制任意长的相似链；不能用《哲学研究》§§65–71 讨论游戏的论证直接证明“哲学没有本质”。E2 仍需要选择相关相似性而非任何相似性。

### 第二层：历史实践、语义与制度语境

- **E3-weak（历史语境约束）**：说明一项活动如何在原生语境与后世翻译/学科化过程中取得“哲学”身份，和 E1/E2 **可以并存**；历史事实不能独自作规范裁决。
- **E3-strong（强构成论/名义论）**：若进一步断言“哲学身份完全由历史实践、语言使用或机构归类所构成”，这才是可能与 E1 的超历史实在本质观竞争的**额外哲学主张**；不能将弱版本自动等同于强版本。

因此 E1/E2/E3 不是三个投票选项，而是：**概念结构竞争 + 历史语境审查 + 明确标记历史构成论的强主张**。各层对照 P-DESC（描述）、P-NORM（规范）、P-INST（制度），防止跨层偷换。  
**结论 L02**：该重构让“如何称作哲学”与“应否称作哲学”可分开争论，但不宣布 E1/E2 中任何一方获胜。

## 3. 六案例压力测试：对象固定、对照先声明

**设计原则**：以现有文本来源和两个明确的**构造性日常活动类型**作有界反例压力测试。先给案例设定“通常正例/通常非哲学局部活动/学科交叉争议”的先验审查角色，再使用相同 Q/A/R/H 观察；先验角色只供检查 H2 的鉴别力，**并非客观真值标签**，不能据此计算准确率、召回率、显著性或样本外表现。  
Q=具体问题；A=默认前提有没有受到审视；R=理由/诠释如何受质疑；H=原生历史实践及现代接受史。某维没有明显呈现时如实写“未见”，不据此自动判负。

| ID / 预设角色 | 固定研究单位及来源等级 | Q / A / R / H 观察（限定性） | 最强异议及本轮判定 |
| --- | --- | --- | --- |
| **T01 典型正例** | 柏拉图《申辩》21c–e 所述苏格拉底对智慧声称的公开检验；A2 Fowler 英译，S01/S15 | Q：何谓真有智慧；A：自称知道可能不真；R：对话反诘；H：雅典审判辩护语境，后世纳入哲学 | 文本不是历史苏格拉底的无媒介记录；`PHILOSOPHICAL_COMPONENT_SUPPORTED`，非所有苏格拉底言行皆哲学 |
| **T02 跨传统正例候选** | 《墨子·非命上》“言必有三表”反宿命论段落；A1 网页传本 S05/S18，SEP B | Q：命论、政治判断如何立言；A：不能仅依口说；R：圣王事迹/耳目见闻/施政后果；H：先秦墨家论战，现代比较归类 | “圣王”标准有权威问题，`fa` 不等于现代科学方法；`PHILOSOPHICAL_COMPONENT_SUPPORTED_WITH_HISTORICAL_QUALIFIER` |
| **T03 通常非哲学对照** | **构造例**：按既定规程反复校准仪器、记录时钟频率；R（非历史原典案例） | Q：读数是否符合规定；A：时钟/规程标准被接受而非重新论证；R：测量误差/标准测试；H：一般实验技术操作 | 高质量专业推理≠一定在做二阶哲学；但若争论时间概念，案例会改变；`NONPHILOSOPHICAL_AS_SPECIFIED` |

| **T05 跨学科边界** | 爱因斯坦 1905 相对论 §1 对“同时性”的概念澄清；A2 英译 S21 | Q：远距同时性如何确定；A：时间读数与同步的默认理解受审查；R：概念定义与物理测量程序；H：物理理论建构 | 可以同时是物理与概念哲学的活动；`CROSS_DOMAIN_CONTESTED`，不能仅由“科学”推出 `¬P` |
| **T06 跨学科边界** | 阿奎那《神学大全》I q.1 a.1、a.8 关于哲学/启示教义及论证的段落；A2 英译 S23 | Q：启示教义与理性知识如何区别；A：理由来源被明示；R：经院式争论并接受启示原则；H：中世纪神学与哲学关系 | 整部神学作品不等于哲学，具体论证可有哲学内容；`CROSS_DOMAIN_CONTESTED`，必须固定片段 |

### 本轮可以实际得出的压力测试结果

1. **Q/R/H 的出现不足以排他识别哲学**：两个技术操作也具有问题、理由及实践背景，不能将这些维度是否出现等同哲学资格。
2. **A 也不是公认的唯一界限**：T05 是概念反思与物理理论的交叉；T06 以何种权威提供理由本身构成争论。领域重叠不证伪共同必要属性。
3. **H 容易循环**：若直接写“哲学史将其归哲学，因此是哲学”，那只是 P-DESC/P-INST 的描述，不能替代 P-NORM 的理由。
4. **T03/T04 是定义清楚的思想构造，而非真实采样的阴性数据**：除既定局部活动外，不可外推“科学/工程全部不是哲学”。
5. **H2 的价值是指导审稿人提出问题和发现争议**；其 `Q/A/R/H` 目前既不是独立分类器，也不是必要充分条件集。不能将表中六个审查角色反过来当作 H2 识别结果。

**结论 L03：H2_DESCRIPTION_AND_ADVERSARIAL_AUDIT_USEFUL；H2_STANDALONE_DISCRIMINATION_NOT_ESTABLISHED。** 这是依据六案例进行的**定性压力测试**，不是科学测量、盲评或跨文明穷举。

## 4. 推荐的实际识别程序（不是“哲学性评分”）

对任何候选 X：

1. **固定粒度**：判断一段论证、一项局部实践、一本书，还是一个主体？不能中途变换。
2. **并列两种归属理由**：P-DESC/P-INST 的历史/语言用法证据，与 P-NORM 的理由及反对意见分别记录；若是非西方传统，保留原生称谓。
3. **利用 H2 四维作描述**：分别记 Q/A/R/H 的原典证据与“不确定”，但不设未经论证的四维总分或阈值。
4. **反向解释**：至少写出一个可以认定其有哲学内容的理由、一个拒绝此归类的理由，审查兼属可能。
5. **结论限定**：用 `PHILOSOPHICAL_COMPONENT_SUPPORTED`、`NONPHILOSOPHICAL_AS_SPECIFIED`、`CROSS_DOMAIN_CONTESTED` 或 `UNDETERMINED`，并注明是局部判断、具体证据及其强度；不能冒称跨文明定理。

该程序只给出**透明可争论的理由**，不保证人人同意外延。其有效性须由其他审稿者用新的非精选例子挑战。
