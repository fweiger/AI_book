# TOPIC-006 · 研究路线

1. **Q01 数据**：先读 [SEC 数据结构与质量](sources.md)，定义准确/完整/时间/版本/许可；输出数据准入规范。
2. **Q02 能力**：比较通用模型、检索、计算工具、Skills、后训练；使用相同基准做消融，不因看见产品声明而推断训练增益。
3. **Q03 产品**：阅读 [MBABench-2.0](https://arxiv.org/abs/2610.31711) 与 [SpreadsheetBench](https://spreadsheetbench.github.io/)，构造专业表格盲测与审计准则。
4. **Q05 长期协作**：定义多日任务状态、审批、恢复和错误升级，设计长时间运行基准。
5. **Q04 预测**：参考 [金融 LLM 评估偏差](https://arxiv.org/abs/2602.14233)，用严格 information-as-of 与无未来函数的滚动评估比较专家/统计基准。
6. **Q06–Q08 治理与迁移**：审查来源、拒答和其他行业的可迁移性；形成有限且可反驳的结论。

每一步输出**证据、反证、未知项、可以复现的实验方法**，不是直接讨论“AI 一定超越人类”。
