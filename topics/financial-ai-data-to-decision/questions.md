# TOPIC-006 · 研究问题

| 问题 | 核心假说与反对解释 | 需要的证据/实验 |
|---|---|---|
| Q01 数据瓶颈到底有多大？ | 正确的数据是重要前提；但完全正确的数据仍可能遗漏决定未来的未公开变量 | 质量维度和缺陷注入实验，记录拒答、纠错、误报及未检出 |
| Q02 哪些能力由训练获得？ | 金融后训练能提高数据语义与判断；对立解释是 RAG+工具+Skills 足够 | 同模型同数据条件下的分层消融，控制样本泄漏 |
| Q03 复杂 Excel/估值模型能否自主完成？ | 生成文件易于实现；专业可维护与公式勾稽更难 | 三表、DCF、LBO、多表格式、可审计性盲测 |
| Q04 预测与解释如何区分？ | 解释历史财报不等于判断未来利润与收益 | 独立时间样本、专家与统计基准、预注册预测 |
| Q05 长期 Agent 缺什么？ | 持续项目需要任务状态、权限、恢复和监督，而非长上下文即可 | 中断、任务更新、权限故障、复盘型长周期基准 |
| Q06 如何验证与拒答？ | 引用不意味着财务数值自动真实；不能用模型自评代替复算 | 来源逐单元格追溯，确定性断言和独立审查 |
| Q07 权限和许可如何限制研究？ | 可检索不等于可以训练/分发；机构数据需要隔离与审计 | 数据许可清单、来源授权边界和访问控制 |
| Q08 能迁移到其他行业吗？ | 数据治理和 Agent 是跨行业问题；预测反身性更偏金融 | 医疗/法律/工业任务横向对比，不混用评分 |

## 竞争性解释
- **H1 数据决定论**：数据质量改善后，通用模型已能覆盖主要金融任务。反证：给定正确数据仍存在推理和建模错误。
- **H2 专项训练必要论**：领域后训练能产生无法由 Skills/工具低成本替代的稳健优势。反证：不训练条件在同等成本下达到同样专业质量。
- **H3 工程工作流论**：真正瓶颈是专业交付、可验证执行和长期项目管理。反证：独立基准表明端到端任务本身已足够可靠。
- **H4 预测非线性论**：财务理解能力提升不保证前瞻预测价值，未公开信息、制度变化和市场反身性可能限制预测上限。反证：在持续滚动盲测中出现稳健超额表现。
