# TOPIC-010｜四帝国比较研究共用协议 V1.0

> **目标：** 对西班牙、荷兰、葡萄牙、法国分别执行可复查的科技—人口劳动/贸易—军事外交—财政五维历史研究，再与英国对照，检验帝国边际收益递减（IMR-01）及竞争性解释。  
> **上位研究：** [AI_book #30](https://github.com/fweiger/AI_book/issues/30)；**后期帝国退出桥**：[TOPIC-005 #20](https://github.com/fweiger/AI_book/issues/20)。国家工作独立Issue/独立研究分支；共用框架但不预设相同结论。  
> **状态：** 研究协议、指标定义与第一轮史料调查；跨帝国统计与因果模型未运行。

## 一、分层因果链和禁止预设

1. **A 科技及组织创新**：导航、造船、火炮、海上后勤、冶金/汞齐法、纺织、印刷/知识传播、股份公司、财务会计与银行；分别给出创新、知识传播、生产应用、军事应用的日期，不允许“所有科学为殖民贸易而发明”的单原因假定。
2. **B 殖民和劳动/贸易**：船运规模、殖民地控制方式、人口（居民stock）、被迫运输人数(flow)、奴役劳动/indigenous compulsory labour/contract labour、金银矿产、种植园、贸易网络、进口/出口、跨境资金流；必须把奴役人口的真实强制和暴力独立记录，不等于货币成本为零。
3. **C 军事及外交**：参战动机与当时盟约、参战/未参战、海战及封锁、殖民据点控制、内战/王位战争、联盟补贴、军事资源、战争持续性；**不能仅凭英方最后获利反推英国主动挑起大陆战争**。
4. **D 财政金融**：国库税收、财政收入、殖民本地税、殖民汇款、政府/公司债务及债息、军费/海军费用、商社利润、外汇/银本位；货币、政体、会计主体、名义/实际及GDP分母须注明。
5. **E 相对产业能力和退出机制**：本土加工制造业、劳动力工资与煤能源、资源诅咒和实际汇率、相对工业竞争、地方反抗/独立、贸易在失去直接统治后能否保留。

**区分四本账**：宗主国国库F、居民私人P、国际资产负债X、殖民政治和当地社会成本S。单个企业VOC不等于荷兰国库；大陆银矿不是统一“非洲奴隶开采”的劳动模式。

**关键地理修正：** 波托西矿位于今天玻利维亚，萨卡特卡斯位于今墨西哥；葡萄牙18世纪主要黄金来自巴西，荷兰VOC更以亚洲航运、贸易、行政与海军成本为研究对象。四国不适用统一“银矿→工业品→帝国衰退”事实模板。

## 三、横向一致字段

- `event_id`, `country_historical`, `year_start`, `year_end`, `domain`(A/B/C/D/E), `observation`, `source_url`, `source_tier`, `inference_boundary`, `verification_status`.
- 金额：`amount`, `currency`, `accounting_owner` (state|company|colonial_treasury|private), `nominal_or_real`, `frequency`, `numerator_definition`, `denominator_definition`.
- 不能混用`colonial_population_stock`, `captive_transport_flow`, `mita_labour`, `company_employment`；也不能将赔款/条约领土声明自动转成实际经济利润。
- `source_tier`: `PRIMARY_ARCHIVE`, `PEER_REVIEWED`, `INSTITUTIONAL_HISTORY`, `RECONSTRUCTED_DATA`, `SECONDARY_SUMMARY`；一个数值可以有多个来源，但仅原始资料年份能给出真值精度，估计值保留估计标记。
- 国界按当时法律政体（伊比利亚联盟1580—1640、英格兰/大不列颠1707、荷兰共和国/巴达维亚共和国、法国王国/共和国等）；若只可核到年份，不伪造具体日期。

## 四、候选因果图和动态检测

`航海/军事技术 + 国家金融和组织能力 → 海军/商社可动员能力 → 殖民据点/贸易收益 → 可征税贸易和信用 → 战争资源`；

竞争性负反馈：
1. `军事联盟/竞争 → 海外战时封锁、船舶损失、战争支出增长 → 海外税收净流量滞后 → 信用危机`
2. `金银财富冲击 → 非贸易品价格/工资上升与实际汇率升值 → 本土可贸易制造衰弱` (资源诅咒)
3. `奴役/强制劳动与殖民统治 → 社会抵抗/治理暴力成本/合法性损失 → 统治终结`
4. `贸易公司向领土政权转变 → 军政费用和融资需求增长 → 贸易中断敏感性上升`

检测顺序：
- **M0**来源和历史事实准入
- **M1**A/B/C/D/E国家年表及事件结构化
- **M2**可比真实财税/舰队/贸易/人口面板和缺失评估
- **M3**竞争性假说与反证、横向对照
- **M4**是否存在较明确的边际收益下降、财政过度延伸或资源诅咒及其时序，含不确定性
