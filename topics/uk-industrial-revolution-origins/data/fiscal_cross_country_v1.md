## 2. 第一项发现：荷兰在财政收入的人均指标上长期领先，但英国不断追赶

同一数据口径下：

| 时段 | 荷兰/英国：人均财政收入 ÷ 生活篮子成本（倍率） |
| --- | ---: |
| 1600—1649 | 5.394 |
| 1650—1699 | 3.140 |
| 1700—1749 | 2.272 |
| 1750—1799 | 2.015 |
| 1800—1849 | 1.750 |

1700—1709的另一项白银计价基准为**荷兰/英国=2.292倍**；1750—1759为**1.736倍**，1780—1789为**1.324倍**。两组数据在“荷兰人均财政收入仍较高、英国相对追赶”方面方向一致，但底层研究可能存在**共同文献与原始数据**，因此这不是相互独立的两次实验复制。

这些结果**不足以**说明荷兰具有更强总量税收、海军预算或更低借款利率，也不能证明税收能力决定工业化。它挑战的是“英国在工业革命前的人均财政动员能力始终世界第一”这种强断言。

## 3. 第二项发现：葡萄牙殖民财政贡献并非持续线性扩大

Costa Table 3（含帝国收入/GDP、剔除帝国收入/GDP）：

- 1500—1549：2.0%与0.8%（约60%收入比例的差额，依据四舍五入值推算）。
- 1700—1749：5.2%与4.1%（约21.2%）。
- 1750—1799：4.7%与3.6%（约23.4%）。

该近似比率是**在相同GDP分母下利用论文发表的四舍五入比值进行算术估算**，不能声称精确帝国财政收入口径。相应作者正文还有年代更细的帝国来源构成变化。高殖民财税参与度不是英国式蒸汽机械化的充分条件。

## 4. 第三项发现：财政负担与战争融资必须成对观察

OBR（2023）直接提供的里程碑：1700—01英国债务/GDP约22%；拿破仑战争前夕约155%；1815年接近180%。其研究表示18世纪重大战争期间中央政府借款峰值约GDP的5%—11%；1694年英格兰银行的成立改变了政府融资能力。

所以一个重要问题是：**高国家财政能力既可能支持战争，也可能带来长期债务负担。** 不能只用征税额解释战争胜负，也不能用高债务直接推论帝国衰落；参考 [TOPIC-005](https://github.com/fweiger/AI_book/issues/20) 处理后一问题。

## 5. 发现的数据口径冲突：不能回避

OBR对18世纪英国税收收入概括为**平均GDP的约8%**，但Costa Table3中英格兰的中央政府收入/GDP为1700—1749年**5.7%**、1750—1799年**6.6%**。

二者不一致。可能来源包括数据边界（税收/总收入、国库/中央政府、纳入地方与战争收入方式）、GDP重建方法、历史年份与聚合口径差异。目前**尚未确定是何种因素造成，也不能擅自消除**。需取得OBR workbook metadata 和Costa底层数据字典作逐条调和。

另：Costa Table 3标注英格兰收入原始数据截至1815年，因此**1800—1849年这一行不应被解释为全50年都有实际观察**；当前CSV已备注该局限。
