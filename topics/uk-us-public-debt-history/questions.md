# TOPIC-005｜因果研究问题优先级

| 问题 | 研究关键 | 验证/反证 |
|---|---|---|
| Q01 首要 | 英国债务高企是否通过利息/税收、外币偿付限制海外援助和军费？ | 政府财政表、票息、支付/税收、外交档案，区分本币国债与美元义务 |
| Q02 首要 | 英国海外证券与直接投资为何在1938–48收缩，政府还债贡献多少？ | BoE原始资本序列，出售/到期收回/投资净流量，官方与私人资本分开 |
| Q03 首要 | 1947年英国退出希腊/土耳其援助，美国如何接手？ | FRUS1947年2–3月、国会援助文件、英财政与国防预算；区分外交选择与强制约束 |
| Q04 首要 | 1956年苏伊士危机是债务危机、美元外储危机，还是外交政策造成金融压力？ | IMF、英美档案、外储/英镑余额、英国账户构成与政策事件 |
| Q05 | 英镑储备地位、英镑区域债权人及海外殖民关系如何演化？ | Avaro(2024)、Schenk(2010)、Paiva Abreu(2017)与BoE档案 |
| Q06 | 债务、殖民政治、产业竞争、战争资产损失哪个是原因、中介或共同结果？ | 多维国际地位代理指标，事件时间顺序与反事实 |
| Q07 | 1815高债务仍扩张、1947后债务率下降仍战略收缩是何种反例？ | 按同一债务覆盖/不同制度时期做比较，不做机械阈值预测 |
| Q08 | 美国当代是否存在类似财政空间、海外资本和全球投射挤出？ | CBO/BEA/IMF/SIPRI/OMB/DoD年度数据、长期路径和其他可能原因 |

先以英国历史因果研究为主体；**美国当代比较须沿变量链映射，不是债务率超过特定数字就出现同样结果**。完整资料见[2026-11-04研究证据台账](RESEARCH_EVIDENCE_20261104.md)。
