# AI_book研究方法沉淀｜TOPIC-005六AI因果审计案例（R5候选）

> 来源：[TOPIC-005 Issue #20](https://github.com/fweiger/AI_book/issues/20) 的 A–D R1、E-R2、A–D R3和 [F-R4终审](https://github.com/fweiger/AI_book/issues/20#issuecomment-6691211843)；本页抽取**可复用的研究流程**，不是从历史案例推导的新定量结论。状态：DRAFT_METHOD / PENDING_REVIEW。

## 1. 可复用问题框架：事实核验 → 机制识别 → 跨域迁移

1. **拆开因变量**：英国“霸权”至少包括相对产业/贸易、金融储备货币、军事投射、殖民政治和外交自主；不同维度变化不同时，不构造任意加权的单年“失霸”事件。
2. **将宏大叙事拆为六条因果箭头**：战争W→债务与资产D/A→财政/外汇约束F/X→投入I→具体撤退Y→地区承接S→相对地位H。每条箭头至少要对应一个原始来源、反证、时点和可证伪标准。
3. **强制列竞争DAG**：W既可能直接影响Y，又可能通过D/I间接影响；海外军事过度承诺可能反过来损伤外汇。要先区分总效应、直接效应和中介，不能“控制一切”反而切断待识别路径。
4. **单位/主体/财年合同**：债务存量≠年度债息；债息/全部财政收入≠债息/税收；英镑对外存款≠国内公债；BoE海外证券名义资本≠FDI净流量；美国$400m授权≠英方同额节余；FY与日历年要桥接。
5. **事件时序防止后因当前因**：1947年2月英援希决定早于7–8月可兑换危机；1956年11月末储备损失和12月IMF提款不允许被写成11月6日决策者已知即时资金；1967撤退方向与1968加速决策必须分开。
6. **时间信息集**：每条历史档案须记录形成、发送、收取、当时是否可见和后期公开时间；时区按GMT/EST并列。不满足“决策时已知”，则不能作为当时因果触发证据。
7. **强制反例审查**：1815高债仍扩张与1914前相对份额下降却绝对产出上升，分别挑战固定阈值及“份额下降=总量萎缩”混淆；反例只推翻强命题，不必否认局部资源约束。
8. **把研究轮次与证据闭合区分**：R1四组提交、E的22问、R3四组逐条答辩、F终审各有可核评论URL；22项有答复≠22项完全解决；R4显示21 PARTIAL、1 UNRESOLVED。
9. **绝不把多Agent当独立数据点**：研究者A/B引用同一BoE表属于一个数据源；意见人数不能给可信度投票。核实“谁实际读过原件、原表还是摘要、有哪些未取得”的审计日志。
10. **跨国迁移检验只能迁移问题**：英国的金美元固定汇率约束不能机械映射现代美元浮动汇率；比较需要匹配制度、融资币种、净息、海外现金支出和国家层级，不预言美国命运。

## 2. 建议的最小主张卡格式

```text
claim_id:
proposition:   # 精确可证伪陈述（不允许宽泛同义扩张）
variable_scope: # 国家、时间、单位、主体、存量/流量、统计版本
source:         # 官方原始URL、文书号、页码/§
reading_level:  # PRIMARY_TEXT / TABLE_TEXT_READ / TABLE_IMAGE_PENDING / ABSTRACT_ONLY / CATALOGUE_ONLY
counterevidence:
causal_link:    # L1-L6；不能只给整段叙事
temporality:    # 形成/发出/到达/决策的时间与时区
status:         # FACT_VERIFIED / PROCESS_SUPPORTED / CAUSAL_PARTIAL / CONTESTED / NOT_IDENTIFIED / REFUTED
missing_to_upgrade:
reviewer:       # 实际核验身份，不能以角色名称代替
review_time:
issue_comment_url:
```

## 3. 对AI自动验证体系的抽象

- **确定性校验交给脚本**：表格合计、比例、单位、时间排序、来源URL、重复来源、文件内主张ID唯一性等可自动检查。
- **人工/模型多源审查保留**：源文是否表达作者断言、同日内阁是否接收信函、英国没有美元约束的反事实；这些不能由简单公式推导。
- **独立裁判只输出证据等级，不决定PR自动合并**；人类维护者审查以后再改变 `INTEGRATED`。
- **变更追溯**：保留R1、R3原帖及修订版，不以最终总结覆盖原有分歧；当新档案改变判断时追加“旧等级→新等级、原文出处、批准人”。
- **失效保护**：`NOT_IDENTIFIED`和`CONTESTED`不能自动升级为“证实”；关键原档不可读时必须在结果中显式留下DATA_GAP。

## 4. 推荐复用场景

- 金融因子研究：回测收益与因果识别分层，幸存者偏差、市场状态共同因及样本外检验分别入台账。
- 经济政策研究：官方会计恒等式与政策效果区分，债务/GDP下跌不等于名义本金偿还。
- AI_book专题讨论：每个Topic保留问题树、原始主张、红队质询、终审、开放缺口、PR人工审查，避免“Agent轮次完成即自动上升为事实”。
