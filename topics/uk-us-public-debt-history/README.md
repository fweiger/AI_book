## 什么算“英国霸权衰落”？

分为经济/工业相对规模、国际资本输出与海外资产、英镑储备国际地位、海军/驻军投射、海外援助与外交自主、殖民政治六个指标域；分别报告起始变化年份，不强行认定在1945/1947/1956一刻集体结束。

## 初步找到的最关键证据

1. 英国官方OBR：1946–1976名义国债约£27bn升至£64bn，债务率却显著下降，主因是名义GDP增长大于债务增量。[OBR](https://obr.uk/box/post-world-war-ii-debt-reduction/)。
2. 英格兰银行1950年调查：其覆盖的海外证券投资名义资本1938–48减少£1.585bn（约45%），战争到1946新增海外商业证券投资几乎停滞。[英国央行原始研究](https://www.bankofengland.co.uk/-/media/boe/files/archive/uk-overseas-investments/1938-1948.pdf)。
3. 1947年英国政府正式告知美国，由于财政金融状况无法继续援助希腊/土耳其；美国提出$400m援助以接手责任。[FRUS同期档案](https://history.state.gov/historicaldocuments/frus1947v05/d36) · [美国国家档案馆](https://www.archives.gov/milestone-documents/truman-doctrine)。
4. Asteris (2013)、Peden (2012)、Tomlinson (2009)、Avaro (2024)、Schenk (2010)等资料说明财政、国际收支、外币负债、产业竞争与国家战略选择可能同时作用。**绝不可把“财政困难”直接等同于“国债本金导致停投”。**

## 美国对照

必须分别检测：债务存量/GDP、净利息/财政收入、财政可调度空间、海外公共援助/基地/军费支出、私人海外资本净流量、净国际投资头寸、美元储备地位、对外短期偿付与美元流动性。2026CBO **预测**债务公众持有/GDP101%、净利息/GDP3.3%；BEA统计2026Q2净国际投资头寸-$22.42tn、2025年底美国海外FDI存量$7.14tn；不得据此直接推断“美国已重演英国”。

## 核心边界

高债务率可以是**解释变量候选**而非历史定律。若债务率下降同时海外实力衰退，必须研究更贴近机制的利息/税收、外储/外币负债和国家战略承诺。下一阶段按时期与事件逐项提出竞争解释、找相反证据和反事实。
