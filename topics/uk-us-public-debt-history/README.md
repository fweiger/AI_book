## 债务变动的核心恒等式

采用统一覆盖口径及名义变量时：

```text
b_t = ((1 + i_t) / (1 + g_t)) * b_(t-1) - s_t + sf_t
b_t : 期末名义债务 / 同期名义GDP
i_t : 债务存量名义有效利率
g_t : 名义GDP增长率
s_t : 当期初级盈余 / 当期GDP（正号=盈余）
sf_t: 其他存量-流量调整 / 当期GDP
```

这是会计分解的基础；多种债务定义下是否仍满足同一式子，要逐一核查。增长不能只看实质GDP增速，还需考虑物价，债务在外币计价时亦需考虑汇率与估值变动。

## 本专题的科学方法

1. **口径识别**：先建立英国/美国两国债务定义桥接表，而不是先凑曲线。
2. **路径归因**：用原始年数据重算年度债务率变动，拆分利率、增长、初级财政、stock-flow四项。
3. **多时期检验**：英国1815、1918、1947后的不同阶段；美国二战、2008、2020与2026基线。
4. **对立假说**：增长、财政整顿、金融抑制/利率、债务重组与统计重分类，各自提出支持证据和最强反证。
5. **后续因果检验**：另建“债务率—国际地位”比较研究，不以时间先后代替因果识别。
