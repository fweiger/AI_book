## 已核对的事实框架（不能直接推出私人动机）

研究文献描述：1879年唐廷枢、李鸿章的修路主张一度获许可，后来因涉及旗地等因素被收回；矿务局随后采用煤河与矿区附近短段铁路相连，1881年建唐胥铁路。铁路随后逐步延伸（详见 [S01](sources.md)）。煤矿与轮船招商局存在经营、人事和资金联系（[S02](sources.md)）。

**不能直接断言**「漕运集团策动否决」「风水纯属幌子」「煤河是为了联合大多数而设计」或「马拉牵引是完整的预谋策略」。它们分别需要批准机关、利益主体、原始奏折、经营资料及因果过程证据。

## 核心学术增量

从二元对立的「愚昧 vs 先进」转向多维比较：**运输网络的替代/互补、分配效应、产权和否决权、政治可执行性、分期建设产生的动态反馈**。但同样必须反对把一切反对意见都还原为私利；真实的文化、主权、安全顾虑可能并存。

## 研究退出标准

- 事故事实：至少有明确出处的时间线与区段。
- 收益主张：具备成本口径、运量、资本支出与旧利益相关者数据，才讨论获利规模。
- 强动机主张：须有当事人的同期记录，且排除明显替代解释。
- 若查档未果：在 [claims.md](claims.md) 中保留「待验证」，不得升级为已证明。
