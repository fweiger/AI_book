# Q01 · 研究型 RSI / 非 RSI 判断标准（v0）

## 两层定义

**过程层 RSI（文献定义）**：研究状态 R_(t+1) 吸收之前已验证实验的结果，下一轮假设分布/候选决策以 R_(t+1) 为条件，且评分合同保持不变。AQuA Section 3、Equation (1) 就属于该有限意义下的研究层递归；并不等于 LLM 自训练权重。

**结果层 RSI（本项目拟验收的更强定义）**：在冻结预算、候选权限、底层模型与盲测的前提下，AI 改变研究策略带来的**独立任务有效研究产出**，相对固定/随机/仅记忆对照有可重现实证提升，并经多重检验及交易成本检验。

| 行为 | 过程层 RSI? | 结果层 RSI 已被证明? | 原因 |
|---|---|---|---|
| 记录失败并调整下一假设 | 可以，若有真实反馈依赖 | 未必 | 仍需等预算、未见任务对照 |
| 只换用更新的 LLM 生成更多因子 | 否 | 否 | 不是研究状态递归效应 |
| 单轮试 1000 个参数取验证集最大 IC | 否 | 否 | 多次搜索产生选择偏差 |
| 每次查看最终测试集后重写 prompt | 否 | 否 | 已污染最终盲测 |
| 双 Agent 审核后认为特征无泄漏 | 否 | 否 | 没有程序性可得性验证 |
| 仅保存笔记，提案不读取历史实验 | 否 | 否 | 没有自适应的研究决策 |
| Thompson Sampling 选择因子或模型方向 | 取决于上下文更新，可能是 | 未必 | 需要隔离搜索次数、底座及预算效应 |
| D 组在独立任务上优于 C 组 | 要有可追踪过程 | 须经门禁后才能认可 | D−C 隔离元调度；另需控制统计不确定性 |

## 必须保留的反证

1. **搜索预算替代解释**：相同时长内有更多有效候选，额外收益可能只因有效实验数增加。
2. **错误继承替代解释**：记忆可能放大未来函数或反复使用被污染的测试指标。
3. **跨任务失效解释**：一次市场状态中形成的调度偏好，在新状态或新特征域未必仍然有效。
4. **权限泄漏解释**：所谓 sealed 若只靠提示词/人员承诺而非权限、不可写数据路径与审计日志，就不是可证明的技术隔离。
