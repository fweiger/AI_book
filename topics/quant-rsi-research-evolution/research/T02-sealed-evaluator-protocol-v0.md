# T02 · A 股 Quant-RSI 冻结评估与四组消融协议（v0 草案）

- 日期：2026-10-29；对应 Q02/Q05/Q06/Q07、C001–C007
- 状态：**协议草案已写，尚未冻结输入、尚未分配样本、尚未执行实验/回测**。
- 依据：AQuA Section 3.1/6/Appendix B；RD-Agent(Q) Section 2.5 / Table 3 / Appendix D.2。
- 不预填股票池、日期、预算、手续费、滑点或任何测试分数；必须由真实可用数据和评估目标驱动。

## 0. 实验目标与可识别效应

核心单位：**独立研究任务 task**（一个问题域 × 特征集 × 预测目标 × 明确数据可得时点），不是一条 tick，也不是一天的收益。

- 过程效应：研究记忆和元调度能否改变「每单位研究资源产生的可复核有效假说数」？
- 预测效应：锁定的候选因子在任务未见时期的 Rank IC / ICIR 是否稳健？
- 决策效应：在可交易约束和净成本下是否有增量收益？
- 归因效应：额外模型调用、更多有效实验、任务选择偏置是否解释表面优势？

三种效应必须分开报告；预测强不自动等于交易强，实验量多不自动等于 RSI。

## 1. 四组严格对照

| 组 | 假说生成与验证 | 经验记忆 | 元任务调度 | 识别作用 |
|---|---|---|---|---|
| A 固定工作流 | 固定研究模板与候选优先级 | 不跨轮迁移 | 固定 | 最小基线 |
| B 普通/随机搜索 | 同一可选研究动作集，按预注册随机种子选择 | 不跨轮迁移 | 随机 | 排除“只要多尝试就有效” |
| C 固定流程 + 记忆 | 与 A 相同生成和验证接口 | 可检索完整正/负结果 | 固定 | C−A：经验记忆效应 |
| D 完整 Quant-RSI | 同一数据/算子/执行权限 | 与 C 相同格式、规则 | 使用反馈更新研究策略 | D−C：元调度的附加效应 |

全组**同一底座模型版本、调用配置、候选合法动作集、代码工具、评估器、任务池、标签和成本**；变化必须写在实验配置差异清单。A/B/C/D 各自运行独立上下文和研究存储，禁止跨组共享盲测经验。

## 2. 预算配平与统计单位

预先冻结每组预算向量：wall-clock 时间、API token / 花费、CPU/GPU 时间、合法评估次数、有效候选数；记录每项实际用量，不以“同样 12 小时”替代所有预算对齐。若多维预算无法同时严格对齐，设置「固定计算成本」主分析和「固定候选/有效评估数」敏感性分析，结果同时汇报。

- 配对单位：同一外部研究任务，A/B/C/D 用相同输入快照和标签协议。
- 重复：不同随机种子、不同非重叠时间块/任务块，**具体数量由预注册功效分析决定**；不制造任意样本量。
- 主要统计：按任务配对的效果差、置信区间、负结果比例；考虑时间序列/股票间依赖，不能把逐笔观测当独立样本。
- 多重检验：记录每个候选和每次评估（包括失败、人工删改与中途停机），预先选定控制方法与主终点；不能仅汇报最优一次。

## 3. 数据与权限的冻结合同

数据快照哈希、版本化 ticker/指数成分历史、复权方法、市场日历、停牌/涨跌停、成交时间、字段单位、交易所规则、原始->派生处理、缺失/补数、标签定义、研究方案哈希、评估脚本哈希；上述内容由隔离评估器掌管。

权限矩阵：
- Hypothesis/Planner：只能看训练/开发资料、白名单字段和验证反馈；不能读取最终盲测标签。
- Experiment Builder：只能构造白名单算子/配置；不得修改数据解码、对齐和评估器代码。
- Evaluator：读取冻结快照，执行可审计因果检查、成本模拟和评分。
- Audit/Promotion：独立读取所有实验账本，只有研究方案冻结后才能进行单次最终测试；新研究必须另设未见样本。

若无法在现有系统中真正实现读取权限隔离，必须标注「流程隔离而非技术隔离」，不得声称已密封。

## 4. 盘中 PIT 与数据可得性门禁

每个字段必须携带原始 event_time、source_receive_time、available_at、修订/补数版本和最早合法决策时间。最早可用时点：available_at 不晚于 signal_decision_time；交易可执行时间还要包含通信/计算/撮合延迟。

强制否决案例：
- 09:30 的因子使用当日 15:00 才完整的全天成交量，哪怕公式文字写“累计至当前”；
- 用收盘后补齐的一分钟 K 线覆盖开盘时实际能观察到的值，然后把回放解释为实时；
- 用当日未来涨跌停状态/后验股票池/复权状态选择开盘交易标的；
- 用未来 tick 重建过去订单方向或依赖未观察到的账户身份；
- 研究系统反复查看最终盲测得分，依据其结果重写研究任务或筛选因子。

对回放与实时差异实行逐字段定位，不以“历史库更完整”作为实时可信的证明。盘中信号窗口与数据截止时间由具体研究任务批准，不默认使用收盘后信息。

## 5. 时间切分与盲测治理

1. **研究开发期**：训练/验证可迭代，开发反馈仅在该期可见。
2. **外层元研究训练期**：从若干已完成且可访问的研究轨迹学习策略；禁止读取外部测试任务的标签或结论。
3. **外部任务期**：按时间或任务域冻结，候选与模型在正式评分前固定；标签跨期的样本须 purge；必要时按最大标签持有区间 embargo。相近股票/同事件的多任务不得通过分配泄漏到不同组。
4. **最终盲测**：权限隔离的测试标签只在一次锁定的审计环节汇总公开；任何后续基于其结果的研究必须使用**新**的未见测试周期，不可重复拿旧盲测作“独立测试”。

没有已确定样本区间和完整标签定义前，以上仅为协议设计，不称已经实现防泄漏。

## 6. A 股标签、真实成交与输出

每条候选固定：
- symbol / universe_asof / event_time / available_at / signal_time / earliest_order_time；
- 具体 horizon 和决策至入场延迟；
- 入场时间、买卖价格、可卖时间、持有 T+1～T+5 定义；
- 真实可成交条件、涨跌停/停牌/流动性、最小交易单位及 T+1；
- 点时点复权与行业/市值/Beta/指数暴露的计算时点；
- 交易成本、冲击和容量模型（在数据和订单机制核验后批准）；
- 原始因子、去极值/标准化、行业中性与计算支持点时点。

如果这些关键字段尚未核验，输出状态为 DATA_CONTRACT_BLOCKED，不允许报告“成功率”或收益率。

## 7. 事前声明的指标和停止规则

**主指标候选**：有效且独立新假说/预算单位（必须先定义“有效”）；按任务配对的新样本净效用。次指标：Rank IC/ICIR、不同 horizon 的净收益、回撤、换手、覆盖率、跨状态稳定性、运行资源、可复现率、负结果重复率。

- 参数选择、优化目标、主要指标、最低可接受覆盖率、最小统计功效与停机阈值，在数据/任务核验后正式**预注册**，不得拿结果再补填。
- 任何权限越界、未来函数、训练与盲测污染、评价器版本变化或成本缺失，都触发 FAIL_CLOSED。
- 中性或负结果必须记入 Failure Ledger；不能因为结果不好就从候选计数剔除。
- 研究上限到期停止并保存快照；不得凭一组“最好看的”结果临时追加预算。

## 8. 审计输出与尚缺前置条件

每组必须导出：task_id、hypothesis_id、run_id、strategy_version、model_version、data_hash、eval_hash、feature_code_hash、seed、所有实验尝试、合法/非法原因、预算消耗、训练/验证反馈、最终 blind score 的访问审计，以及复现说明。

尚缺：具体真实数据范围、字段字典/实时到达日志、可运行评估器权限机制、成本与容量定义、任务池定义、功效分析。上述缺项全部阻止启动正式“证明 RSI”的实验。

**结论**：本文件完成了设计级协议草案，不构成实验成功、不构成已经实现隔离、不包含任何虚构交易样例。


## 9. 公开源码审计后的硬门禁（2026-10-29）

完整静态审计见 [RD-Agent 源码审计](RD-Agent-source-audit-2026-10-29.md)。本项目在设计上修正以下高风险路径：

1. **外层测试集隔离：** RD-Agent/Qlib 的公开默认链路中，SignalRecord 默认预测 test，SigAnaRecord 从 test 标签计算 IC，PortAnaRecord 使用测试期回测；这些 metrics 又进入实验反馈和下一轮 Bandit 选择。我们的研究控制器只可使用训练/验证反馈，最终盲测只能由独立 evaluator 在方案冻结后读取一次。
2. **标签跨界 purge：** Qlib 标签 Ref($close, -2)/Ref($close, -1)-1 依赖未来两期价格。时间切分必须基于真实交易日历生成 purge/embargo，并对每个边界写单元测试；对于 T+h 标签，至少审计 h 个交易日的跨界样本。
3. **Bandit 反馈合同：** 行动前 context、action、资源预算和验证集 outcome 必须分别记录；用预注册的验证集增量效用，不得用外层测试指标更新策略。指标尺度需规范化，指标键缺失必须报错，不得静默填 0。
4. **成交协议：** 论文文字的“开盘调仓”与配置的 deal_price=close 必须在我们的任务合同中拆分为信号可得时间、决策时间、最早下单时间、成交时间和成交价格。
5. **频率适配：** RD-Agent 默认因子路径使用日线并拒绝一分钟间隔输出；我们复用现有数据接入，在 adapter 层适配日线/分钟/Tick-L2，不复制或重构数据接入。
6. **交易成本与容量：** 统一 9.5% 涨跌幅阈值、固定费用和零默认冲击成本仅是示例配置，不作为真实 A 股执行模型。

机器可读契约模板位于 [a-share-data-contract-v0.json](a-share-data-contract-v0.json)，结构检查脚本为 [validate_quant_contract.py](../../../scripts/validate_quant_contract.py)。普通校验只确认模板结构与阻塞状态；只有将真实字段、时间语义、标签、成本、分段和所有 gate 全部核验并冻结后，才允许使用 --strict 通过正式实验预检。
