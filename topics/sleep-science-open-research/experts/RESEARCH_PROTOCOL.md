# 权威专家研究与证据审查协议 v1

## 1. 三层判别互不混淆
**人物权威性**：原创学术贡献、跨实验室引用、独立验证、跨领域影响、方法设计质量和持续性；**论文证据可靠性**：研究设计、样本/物种、干预与对照、盲法/随机化、可重复性、统计与替代解释；**临床可迁移性**：人体直接证据和临床指南。任何一项都不能从“专家头衔/高引用量”自动推断另两项。

## 2. 每位专家的最小档案
- 稳定 EXP-ID、别名与 ORCID/OpenAlex、历史及现机构（核验日期）、主要研究问题、原创发现、关键合作者和竞争实验室。
- 按年份列原创论文（优先 2 篇）与经典综述（如有）；区分先发现者、机制解释者、理论整合者。
- 为每个核心结论寻找至少一个*非同团队*后续检验；若只有同团队复验则标未完成。
- 记录最强反例或方法争议、同行批评、失效外推、对 Mxx 与 SLxx 的影响。
- 评估实验方法：遗传家系/模式动物突变、光遗传/电生理、PSG/EEG、强迫去同步、随机交叉、队列、荟萃分析等。

## 3. 引文网络不是权威排行榜
- 从每个种子 SP-ID 向后追参考文献，向前追后续引用，再对合作与跨团队复现分类；保留 DOI、OpenAlex Work ID、ORCID 和查询时间。
- citations = 参考文献存在；语义必须另标 **BACKGROUND / METHOD / SUPPORT / CONTRADICT / INDEPENDENT_REPLICATION / CRITIQUE / UNCLEAR**。
- 共同作者引文不属于独立验证；综述的引文覆盖广，不能与原创论文的引用数直接比较。
- 对年份、学科和论文类型做敏感性分层；至少比较原始研究-only 与全部论文；报告分母和未匹配文献。
- 元数据中的作者别名/重名不可自动合并；Russell Foster、Jan Born 等需 ORCID 和原始署名复核。

## 4. 证据入库门槛
- **L0**：题名/转述线索；不写科学结论。
- **L1**：出版者/DOI/PMID 元数据核验；可以登记作者与论文索引，不声称阅读全文。
- **L2**：阅读摘要并校验对象、研究设计与主要结论；结论必须带对象限定。
- **L3**：阅读可合法取得的全文相关方法、结果、图表；记录精确定位。
- **L4**：至少两条独立证据交叉检验，记录矛盾、局限和证据可迁移性。
- 现有样本专家 SP 关系为 L1，不因引用次数或奖项自动升级 L2/L4。

## 5. 从新论文到框架的增量流程
OpenAlex/PubMed/Europe PMC发现 DOI → DOI 与现有 S/X/SP 去重 → 专家身份确认 → 原始论文方法与阅读层级 → 归属 M00–M10（多个模块可以并列）与 SL01–SL08 → 写跨模块研究问题 → 独立复现/反证 → Issue #29 候选 → PR 审查 → 合并后更新 C-ID/图谱/版本。

## 6. 质量限制和复查
- **动物实验**必须记载物种、性别、模型和处理条件；张二荃 2026 小鼠寿命研究不能直接变成人类抗衰结论。
- **自然短睡眠**必须区分自报睡眠时长、活动记录、PSG 及客观日间功能，不能推导所有短睡者可安全少睡。
- **争议**需要并列保留相反结果，如脑清除理论；“被引用”不是“被证实”。
- **公开仓库**只存文献元数据、原创分析、合法短摘录；不写个人健康信息、私有资料和未经授权全文。
