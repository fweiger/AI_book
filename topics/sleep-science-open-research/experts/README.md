# TOPIC-009 | 权威专家—论文—方法论研究库（V1）

本库是 TOPIC-009 的**横向学术证据索引层**，不是第十二个 M 模块。M00 为定义/测量，M01–M09 为机制，M10 为睡眠障碍分类；SL01–SL08 为结果/表型。专家、论文和方法都是可以同时关联多个 M 模块的实体。

## 双入口结构
- **按问题进入**：M00–M10 / SLxx → 关键机制问题 → 关联研究者 → 原始论文 → 对立证据与方法核查。
- **按研究者进入**：EXP-xxx → 研究主线与原创贡献 → SP-xxx 原始论文 → 对应 Mxx → 关联理论/复现实验。
- 同一论文只在种子论文库登记一次 DOI；不复制各 M 模块的论文全文或既有 S/X 来源卡。
- 生物钟研究（张二荃）、睡眠遗传学（傅嫈惠）与睡眠稳态模型（Borbély）相互关联，但不把研究领域交集当成因果结论。

## 首批真实采集范围（2026-11-14）
OpenAlex 核对了 37 篇论文，其中 30 篇原创研究、5 篇综述、1 篇方法论文、1 篇 Perspective。共 2,687 个参考文献引用记录，去重为 2,440 个作品 ID，2,412 条取得扩展元数据；37 篇内部直接引用 50 条；得到引用至这 33 位专家署名文献的关系记录 830 条、外部候选作者 468 位（至少出现在 3 篇种子论文的参考文献中）。仅把 33/37/50 的紧凑可审查元数据放进本公共仓库。

**界限**：这是人工选种的*参考文献出边*分析，没有抓全全球的入边引用，更不是文献完整全文审查。后续不能称之为已完成全球完整专家排名，也不能根据一条引用判断实验已复现。
