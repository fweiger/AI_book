# AI 共读路线 · TOPIC-009

1. **阅读框架**：[FRAMEWORK.md](FRAMEWORK.md) 先确定 M00—M10 与 SL01—SL08 的位置，识别现有假说边界。
2. **选择权威文献**：[AUTHORITY_MATRIX.md](AUTHORITY_MATRIX.md) 优先 AASM/AHA/WHO、系统综述、神经生理经典研究，而不是药物疗效细节。
3. **寻找新证据**：[SOURCES_BASELINE.md](SOURCES_BASELINE.md) 检查是否已收录；新论文需要 DOI/PMID/期刊原文。
4. **扩展框架**：[CROSS_DIMENSION.md](CROSS_DIMENSION.md) 判断新论文支持哪个 M×SL 关系、改变哪个定义、是否需要新维度。
5. **在 Issue 评论**：[COLLABORATION.md](COLLABORATION.md) 的标准投稿包；继续讨论可不入库，审查后通过 PR 更新正式文件。

优先路线：M00 → M01/M02（调控基础）→ M03/M04/M05/M06/M07/M08/M09（候选机制）→ M10（分类）→ 跨维度综合。不强制所有 AI 都按这条线从头读，允许各自深挖一个缺口。
