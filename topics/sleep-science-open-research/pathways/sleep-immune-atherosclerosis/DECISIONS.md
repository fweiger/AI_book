# 科研方向决策台账（保留反对意见）

本文件记录来自六份讨论，尤其最后一份博士课题方向纠偏的**选题决定**，不是实验结论。反对意见不删除，防止新聊天反复推荐已否定的方向。

| 方向 | 决策 | 主要原因/重新进入条件 |
|---|---|---|
| 以血管支架/重建后睡眠改善为首要科学终点 | **不作为主课题** | 研究目的应服务卒中前可干预性，而非证明手术改善睡眠；可作为反向因果辅助问题 |
| 围术期脑微小缺血损伤 | 暂列扩展 | 可连接认知结局；但不能凭借手术量就取代“睡眠—免疫—斑块”中心链 |
| 历史 PSG 与多年后血管结局配对 | 条件性保留 | 只有证实**同一人、睡眠早于血管事件**且病例数/偏倚可接受才升级 |
| 卒中后睡眠—免疫相关 | 不作主要一级预防研究 | 卒中病灶、住院、治疗与睡眠的多向混杂较重，且易丢失斑块机制 |
| 重新建立大规模颈动脉斑块空间组学图谱 | **避免重复** | 优先借已有公开图谱定位候选；针对性新样本配对验证是可保留的独立问题 |
| 睡眠/MRI/CEA 的前瞻同患者配对 | **保留、条件优先** | 可从零前瞻采集；绝不把 CEA 标本作为全部病例的硬性入组条件 |
| 夜班者 ROS 清除剂＋DORA | 远期前临床/伦理研究候选 | Orexin 受体拮抗的直接免疫效应与睡眠修复效应可能冲突；无人体卒中预防依据，不作自行用药建议 |
| 只按三高/非三高分组 | 作为效应修饰和稳健性分析 | 三高分层本身不是足够的新颖性来源；用药和时间先后不能忽略 |

## 2026-11-14 新增竞争研究发现

- **2026 安贞本院近邻研究**：已发表冠心病 1,178 人的自述睡眠时长—NLR—OCT 薄纤维帽斑块分析，故不再用“睡眠时长＋NLR＋斑块易损性”作为原创主假说；改用真实客观微觉醒、颈动脉、临床时间维度和功能免疫形成差异，仍要全量查新。
- **2021–2022 年已有 CEA 组织研究**：OSA/SDB 与 MCP-1、氧化/脂质和组织炎症标记已有人验证；只有非呼吸觉醒的事件级分离及同患者时间链才可能形成新的增量。
- **方法硬门槛**：不能把“总觉醒指数−AHI”当作非呼吸相关觉醒；如无法读取原始事件评分，则需改变课题标题或完善采集能力。

**当前研究组合**：卒中前的客观睡眠与临床斑块/免疫队列为核心；适量配对组织作机制验证；“哪种睡眠破坏最危险”可作动物比较分支；可逆性/药物联合单列高门槛候选，不把它包装成两年内已能证明降低卒中的方案。

## 2026-11-14 第三轮研究选择

- **值得继续：觉醒事件的“频率”与“单次生理反应”分离**。2026 Mayo Clinic 自发觉醒/HR/PTT 实验已占据短时响应题目；我们的增量只能是经事件级排除呼吸诱因后，与同人 MRI/免疫表型的独立关联及复验。
- **必须谨慎：非呼吸性微觉醒不等于完全排除隐匿性呼吸负荷**。AASM 需要识别低通气伴觉醒、RERA；ASA 补充分类是另一套明确公布的研究口径。无法重判 RERA 时，该变量的特异性推断须降级。
- **临床主要终点不提前写死为 IPH**：以盲态影像质量、IPH 事件数和读者一致性决定是否具备主要结局可行性；如需换连续斑块负荷，必须在查看暴露—结局关联前预注册。
- **不扩张实验规模**：P02 睡眠方式比较保留独立动物分支；P03 限定一个预设主要免疫指标；CEA 病理仍是非手术 R2 研究的机制扩展。
