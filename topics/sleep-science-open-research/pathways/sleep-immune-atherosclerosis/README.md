# PATH-ASCVD-01 · 睡眠—免疫—动脉粥样硬化：面向卒中预防的研究路径

状态：**RESEARCH_PORTFOLIO / 候选研究体系，非因果定论** · 所属专题：[TOPIC-009](../../README.md) · 版本对应 TOPIC-009 v0.3.2（方法深化完成后生效）。

## 一个总问题
**非呼吸相关睡眠碎片化及不同睡眠破坏方式，是否通过可识别、可调节的神经—免疫过程影响动脉粥样硬化斑块易损性和进展，进而提供卒中发生前的风险干预窗口？**

明确区分：现有动物实验机制、人群观察性关联、前瞻时间顺序、临床机制配对、真实干预获益。**不能从改善睡眠或炎症指标直接推出降低卒中发生率。** CEA 标本和高分辨 MRI 是验证工具，不是全部研究对象的入组门槛。

## 与既有睡眠科学体系的关系
M00 定义睡眠暴露；M01 负责睡眠稳态/睡眠剥夺；M02 负责倒班与节律；M03 自主神经及高唤醒；M04 三高中的代谢相关影响；M06 负责 OSA/间歇性缺氧鉴别；M09 负责行为时序。免疫/炎症属于 [Q11](../../questions.md) 提出的跨维度缺口，**本路径不擅自创建 M11**。M05/M07/M08/M10 在具体实验需要时引用，不因本路径被强制纳入。

## 科学定位与隐私
以未发生卒中的风险识别和机制解释为临床主方向；手术组织是机制验证亚队列；动物睡眠破坏方式对比是机制拓展；组合用药是尚需伦理、药理和初步动物结果支撑的**远期候选**。不发布个人病历、可识别记录、未经授权的院内原始数据；不将来自讨论的医院资源数当作已经审计的事实。
