# TOPIC-014｜古今中外哲学思想体系：四论主架构 V0.2

> 2026-11-17｜研究草案｜权威任务：[Issue #66](https://github.com/fweiger/AI_book/issues/66)｜审核：[Draft PR #67](https://github.com/fweiger/AI_book/pull/67)。不是 main 正式知识。

## 一、不可替代的主轴

**本体论（O）—认识论（E）—价值论（V）—方法论（M）**，始终是研究古今中外每一种哲学思想体系的四个核心问题域。顺序只是文档呈现顺序，并不宣称历史中的所有思想家都承认这四项具有固定的基础—派生关系。

- O 本体论：什么存在？世界、实体、关系、变化、心灵、因果、自然与人是什么？
- E 认识论：知识与真理是什么？感知、经验、理性、直觉、语言、见证、知识来源及限度如何成立？
- V 价值论：什么是善、正当、幸福、德性、自由、正义、美或解脱？理由何在？
- M 方法论：该哲学家/学派如何进行论证、探究、反驳、诠释或自我修养？此处分析的是原思想体系的方法，而非本研究的工作流程。

**时代、地区、文明、人物、学派、著作都是检索信息，不能另起一套分类来覆盖或替代 O/E/V/M。**

## 二、统一的四论研究卡

每个哲学思想体系必须具备如下字段，缺乏证据必须标为待核而不是填猜测：

| 字段 | 要求 |
| --- | --- |
| T-ID / 思想体系名称 | 以思想体系/学派为对象；同一人物不同时期可拆版本 |
| 历史/地域/语言/原著 | 只用于定位，需记录年代与版本不确定性 |
| 原生结构 native_structure | 记录该传统自身怎样组织哲学，如斯多葛物理学/逻辑学/伦理学三分 |
| O 本体论 | 核心问题→命题→论证→异议→原典定位→证据级别 |
| E 认识论 | 核心问题→命题→论证→异议→原典定位→证据级别 |
| V 价值论 | 核心问题→命题→论证→异议→原典定位→证据级别 |
| M 方法论 | 核心问题→该思想体系所用方法→适用条件→争议→原典定位 |
| O/E/V/M 内部关系 | 标注依赖、反驳、重构、冲突、并列或不可通约，必须有文本证据 |
| 体系整体结构 | 哪一个/几个论域在该体系中起枢纽作用，如何形成系统；不能先验假定哪项第一 |
| 文本审查 | 原典已核段落、学术二手、待核推断分别记录 |

这样从任意一个“本体论”问题都可以深入该学派的认识论、价值论、方法论；从任意一个学派也能完整看到其四论回答。

## 三、古今中外如何围绕四论组织，而不是跳出四论？

- 历史检索：按时间过滤体系卡，查看一个时期的 O、E、V、M 四论回答以及它们相互制约的方式。不强迫中国、印度、欧洲使用相同的历史分期。
- 地域检索：按中国、印度、希腊罗马、伊斯兰世界、欧洲、非洲、拉丁美洲等检索哲学体系，输出仍是四论卡而不是地区杂谈。
- 思想家检索：从孔子/墨子/亚里士多德/龙树/朱熹/阿维森纳/康德等文本提炼四论，而不是先为人物贴四个标签。
- 跨体系比较：例如“知识何以成立”，先在 E 认识论中比较各传统的实际回答，再回到该体系的 O/V/M 中解释其理由。
- 传播/影响检索：只有存在可核查的翻译、师承或引用链，才可标为历史影响；相似但没有证据的思想只能称类比。

## 四、两层哲学解释必须分开

**层 A：作者/学派原生思想**——它原本使用了哪些概念、问题结构与推理方式？

**层 B：研究者用四论重新组织**——我们分别将其归入 O/E/V/M 的依据是什么？哪些项目无法对应？

这并不是放弃四论，而是确保四论分析没有改变原典本意。所有思想体系都经过四论比较，但四论的研究坐标不等于作者当时实际使用的学科分类。

## 五、思想体系不等于四栏关键词

完整的哲学体系卡至少应该包含四论的命题与论证、四论之间的箭头关系、关键争议、最强反例、源头文本及其历史变化。例如朱熹的理气论（O）怎样连接格物致知（E）、德性完善（V）与居敬穷理（M）；而这项连接必须由朱熹相关原典核查，不能由现代研究者猜测。

## 六、后续阶段仍然围绕四论

- P0 本轮：锁定四论格式，建立覆盖古今中外的统一四论候选矩阵。
- P1：选择墨家、亚里士多德、龙树、阿维森纳、朱熹、康德等开展深入四论原典卡研究；每条争议找定位文本与异议。
- P2：分别建立 O、E、V、M 四个全球横向专题：同一问题如何被不同文明与时代回答。
- P3：研究 O↔E、O↔V、E↔V、M↔其他三论的关系网络和竞争性系统组织。
- P4：继续覆盖其他文明思想、现代流派、思想传播；组织独立审稿。

**唯一下一步**：把墨家与亚里士多德的四论卡深化到可定位的原典段落与内部关系，再复制方法扩展其他思想体系。

## 七、错误防护

不要将“早期孔子思想”等同所有儒家，不要以一种“非洲哲学”代表全非洲，不要把佛教“空性”简化为虚无，不要把阿维森纳仅当亚里士多德的复制者。明确分离“思想家的方法”与“研究者的检索方法”。尚未见原典则保留 secondary_only 或 unverified。
