## 中心问题

本体论、认识论、价值论、方法论之间是什么关系？它们在不同哲学传统中是否构成同一层级？有没有必要用一套既能比较、又不会消除各传统独特性的“哲学体系地图”把它们连接起来？

**本专题的基线判断（研究框架，不是古代哲学家的原话）**：

1. 四论是一套**问题轴**，不是世界唯一的、永恒的四分学科结构。
2. 历史上的哲学体系可能采用与四论不同的分法；先保留其自身原生结构，再尝试建立跨体系映射。
3. “方法论”的元层性质与其他三项并不完全对称；逻辑、语言、哲学史也不能被忽略。
4. 有效的体系既应有概念区分，也需要说明概念之间如何相互支持、冲突和限制。

## 第一阶段的明确发现

- [亚里士多德《形而上学》Γ.1, 1003a21](https://beta.perseus.tufts.edu/urn:cts:greekLit:tlg0086.tlg025.perseus-eng2:4/)：直接讨论“作为存在的存在”；不能据此证明现代四论分类古已有之。
- [康德《纯粹理性批判》，先验方法论·纯粹理性的建筑术（A832/B860）](https://web.stanford.edu/class/history34q/readings/Kant/CritiqueMethod.html)：哲学体系需要有内在结构，不是知识列表堆积；这是研究系统哲学如何组织的原文锚点，而非本研究框架得到康德直接认可。
- [休谟《人性论》3.1.1.27（SBN 469–70）](https://davidhume.org/texts/t/3/1/1)：指出从“是”转到“应当”需要说明其推理关系；其更强的现代诠释存在争论，不能直接将休谟简单等同于所有规范论断均不可从事实推导。
- [SEP Stoicism](https://plato.stanford.edu/entries/stoicism/)：斯多葛哲学曾以物理学、逻辑学、伦理学三部分组成互相连接的体系，是四论并非唯一历史划分的反例。
