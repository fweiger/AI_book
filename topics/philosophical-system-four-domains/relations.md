# M1 研究假说｜四论关系的三个竞争性模型

> 这不是“哲学史已经证明只有三种模型”的论断。以下是为 TOPIC-014 #66 设计的**比较框架**。每条映射都是解释性重建；原典应核查到具体段落，再评估它是否成立。

## 模型 A｜本体论优先 / 存在先行

**结构**：对存在与基本原理的理解 → 影响知识的对象与限度 → 价值及探究方式。

- **文本锚点**：亚里士多德《形而上学》Γ.1, 1003a21–32（S01）提出一门研究“存在之为存在”的学问，并区别于各专门学科。
- **分析意义**：哲学研究可以围绕存在结构、原因和原则组织，而不必先要求所有问题都从现代认识论概念起步。
- **重要限制**：亚里士多德同时研究知识、推理、伦理，不是“只做本体论”。“存在先行”是本研究对这类研究入口的概括，不是引文。
- **反对意见**：若关于存在的一切主张都要由知识手段得到辩护，优先研究“存在”并不自动免除认识论的限制。

## 模型 B｜批判/认识条件优先

**结构**：反思认识条件及界限 → 检查形而上学判断的合法性 → 在可论证的范围内组织系统。

- **文本锚点**：康德《纯粹理性批判》导论 VII（S06），探讨纯粹理性批判作为对知识先天来源及限度的审查；“先验方法论·建筑术” A832/B860 讨论系统统一性。
- **分析意义**：并非所有形而上学主张都可以越过知识能力的批判；哲学体系应追问其合法性条件。
- **重要限制**：不能说“康德否定本体论”或“认识论完全生成所有存在”——这些都是需进一步辨析的过度概括。
- **反对意见**：对认识条件的研究本身可能包含对主体、经验、世界等的本体承诺；认识优先未必逻辑上先于一切本体论。

## 模型 C｜相互构成 / 交织式组织

**结构**：存在—认识—价值—方法之间存在双向约束；从具体思想传统内部的概念关系出发，不默认同一排序。

- **比较锚点 1（历史事实）**：斯多葛学派按物理学、逻辑学、伦理学组织相互联系的哲学部分（S08），这既不等于 A 也不等于 B 的简单直线。
- **比较锚点 2（现代解释）**：SEP《Epistemology in Chinese Philosophy》（S12）指出，中国思想传统中的理解、关系、道、知行等具有自身的概念结构，不能未经检验就全部转译为西方经典知识论。
- **比较锚点 3（现代解释）**：印度的 Nyāya/Vaiśeṣika 及新正理学传统将逻辑、论辩、知识来源与本体分类紧密联系（S13）；这说明可从知识获取与范畴结构的连接来研究哲学。
- **反对意见**：若一切都相互依赖，可能无法指出某个具体思想体系的原理优先性；这种模型也容易滑入“什么都相关”的空泛说法。

## 三种模型如何比较（暂定判准）

| 判准 | 要观察什么 | 不能冒称什么 |
| --- | --- | --- |
| 文本忠实性 | 是否有具体段落支持该模型的哲学家归属 | 不能仅凭哲学家名气判定 |
| 内部一致性 | 概念前提是否冲突、是否循环依赖 | 不能把“复杂”解释成“矛盾” |
| 覆盖与边界 | 能否解释原典的核心议题及例外 | 不能以遗漏支线掩饰模型不足 |
| 跨文化适配 | 是否先保留原语言与原有概念关系 | 不能以西方四论术语取代原典 |
| 批判开放性 | 是否保留反例、竞争解释与修订依据 | 不能以 AI 票数决定哲学答案 |

## 最重要的元问题

> 我们是要提出某一个新的完整哲学教义，还是要提出一张**可比较多种完整哲学教义的元哲学地图**？

目前 TOPIC-014 按 Issue 目标选择后者。若未来要提出新的规范性哲学学说，需要独立论证其核心前提，不能把研究索引当作本体论、认识论或伦理学结论。
