# TOPIC-014｜四论理论谱系：从古今中外主要争论理解哲学体系（研究草稿 V0.6）

> 2026-11-17；[Issue #66](https://github.com/fweiger/AI_book/issues/66) / [Draft PR #67](https://github.com/fweiger/AI_book/pull/67)。
>
> **研究问题**：在本体论 O、认识论 E、价值论 V、方法论 M 四个固定主框架内，各时代与传统究竟提出哪些相互竞争的理论？这些理论为什么会形成思想体系？
>
> **证据说明**：本文件为**比较研究与研究假说（S/H）**，主要依据 SEP 权威学术二手条目；没有宣称逐本原典精读。术语和内部关系均需落实到具体著作才能由“候选解释”提升为文本确认。

## 总原则：固定四论，不把流派误当四论本身

| 四论 | 研究对象 | 研究时必须区分的两个问题 |
| --- | --- | --- |
| **O 本体论** | 什么存在、存在者有哪些基本结构、什么使某物成为其所是 | “事物存在什么样”与“论者声称什么存在”不是同一事；本体论也不等于全部形而上学 |
| **E 认识论** | 什么算知识，如何证成、可能误认什么 | “经验/理性/证言如何形成信念”与“这种知识是否正当且真实”不等价 |
| **V 价值论** | 善、幸福、正义、义务、解脱、美和人生意义为何有价值 | “何为善”与“什么行为是义务”相关但不能混为一谈；价值存在论和规范伦理学也不同 |
| **M 方法论** | 原思想体系提出、检验、辩护主张所使用的方法 | 该思想家自身的哲学方法 ≠ 本专题的文献检索方法；方法还要按对象适配 |

## 四论逻辑链的严格判读规则

**不要把 O→E→V→M 当成所有哲学体系的通用因果链。** 研究时至少区分六种有不同证明责任的关系：

1. **对象依赖（O⇄E）**：知识所认识的对象与知识的界限互相制约；但“先研究 A”不代表“A 逻辑上决定 B”。
2. **规范正当化（O/E→V）**：说明为何自然、人性、天或知识可以为“应当/善”提供理由；须指出额外的价值前提，不以事实推出应当为当然。
3. **探究方法约束（M→E）**：方法支持或限制知识声称；必须说明该方法的适用领域。
4. **实践反馈（V→E/M）**：解脱、德性、正义等目标引导认识和研究方法；并不意味“有益即为真”。
5. **概念共同建构（O/E/V/M ⇄）**：不同论域共同使用的核心概念如“道、理、空、自由”，既不可强拆，也需追踪具体推理。
6. **历史影响 vs 问题类比**：只有师承、译本、引用或传播史证据才能标历史影响；存在相同问题仅为“可类比”。

## 核心跨传统争论（最小研究议题）

- **CROSS-01｜事物的真实结构与知识对象**：柏拉图理念/亚里士多德实体/中观无自性之间确有可比较问题，但不意味着它们谈相同“本体”概念。
- **CROSS-02｜天与善、自然与道德**：墨家、斯多葛、阿奎那具有“秩序支持规范”的类似结构；可比的是推理前提与规范桥梁，而非其“天/神/自然”必然同一。
- **CROSS-03｜知与行**：朱熹、王阳明、实用主义均重视知识与实践关系，但良知、格物、实验探究的知识概念不同，历史影响不能想当然。
- **CROSS-04｜确定性、怀疑与认识界限**：笛卡尔、休谟、康德、胡塞尔各自采取不同方法，不能统称为“一般怀疑主义”。
- **CROSS-05｜认识与解放**：佛教解脱、批判理论解放、拉美解放哲学和女性主义知识批判可以比较价值目标如何影响方法，但其“解脱/解放”不属于同一种政治或宗教概念。
