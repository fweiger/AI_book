# CASE-NLD-001｜荷兰殖民贸易帝国第一轮证据审查（M0）

**权威Issue**：[AI_book #33](https://github.com/fweiger/AI_book/issues/33) · **父主题**：[TOPIC-010 #30](https://github.com/fweiger/AI_book/issues/30) · **状态：史料与成本口径首轮审查，完整VOC会计账本及国库对照未下载。**

## 第一轮结论

荷兰是“经营规模仍增加，但盈利能力和融资稳定性变差”的**最清晰第一轮案例**。荷兰国家档案馆VOC历史目录明确记载：亚洲属地军政开销不断增加，公司对荷兰共和国本土货物拍卖所得依赖提高；1780年第四次英荷战争爆发后回航和拍卖受阻，VOC流动性与信用陷入危机，随后需政府支撑。1795后政体变化促成国有化，VOC特许权在1800年1月1日失效。〔[Nationaal Archief](https://www.nationaalarchief.nl/onderzoeken/archief/1.04.02/beschrijving/context)〕

## A 科技—组织
- 荷兰领先的专业造船、全球航运、海上导航、资本市场和股份公司组织是**早期优势**，不应把荷兰衰落解释成“没有科技”。
- [英荷财政海军国家比较研究](https://www.cambridge.org/core/books/abs/war-trade-and-the-state/dutch-and-english-fiscalnaval-states-a-comparative-overview/B8131FA5C932F5387B4B950A99BCA9CF)认为两国都能动员庞大舰队与金融资源。这是与英国技术共享/扩散的合理对照。

## B 人口与贸易
- VOC更依靠亚洲的胡椒、香料、纺织品、航运、贸易据点和殖民控制，**没有西班牙式美洲银矿→宗主国国库的同一主链**。
- 荷兰国家档案馆历史重建：VOC从欧洲出发人员在1602—1700约**317,000**人，1700—1795约**655,000**人；整段运营约装备**4,700艘**远洋船。该数值是公司船运流量，不是受控人口或同时活跃舰队规模。〔[国家档案英文引言](https://www.nationaalarchief.nl/sites/default/files/afbeeldingen/toegangen/NL-HaNA_1.04.02_introduction-VOC.pdf)〕

## C 军事和外交
- 英荷海战使英荷争夺海运市场；但1688年后荷兰与英国出现政治协调和共同对法作战。**英国并非始终与荷兰为敌**。
- 1780—1784年第四次英荷战争与公司贸易阻断同时发生；1795年法国入侵和政权更迭是另一个独立强冲击。

## D 公司财政与政府财政（关键）
- VOC用于装备船舶、采购亚洲货物、送出资金及资源的“equipage”开支：1640—1700累计约**3.70亿荷兰盾**，1700—1795累计约**16.08亿荷兰盾**。注意前后期间分别约60年和95年且货币购买力不同，不可只比较合计倍数就断定成本增速超过利润。
- OECD Maddison的经济史综述亦指出亚洲军事和行政开销是18世纪VOC利润率下降的因素；这必须通过VOC利润、现金、借款、分红和运营资金的**公司账本**来检验，不能用它替代荷兰国家总税收。

## E 退出与强反例
- VOC在1800年丧失法人特许权，但荷兰在印度尼西亚的殖民统治继续存在，并经历19世纪进一步重建。因此**公司财务崩溃≠宗主国殖民网络立刻消失**。
- 其他竞争解释：亚洲香料价格下降、地方反抗、腐败/代理人问题、固定高分红及欧陆战争；这些可能与战争封锁共同作用。

## 候选量化检验
- H1：`company_military_admin_cost/revenue`与`interest_burden`随着地区领土控制提高，并在1780—1784受封锁激化。
- H2：`cash_sales_in_Amsterdam`中断造成流动性危机；如果费用长期不高但净货物流入断裂能解释危机，则纯粹“维持成本递增”不充分。
- 反事实：可不采用领土统治而保留亚洲贸易时，公司可节省多少守备成本？港口贸易额不等于VOC超额利润。

**现有成果：** [13个事件](events_m0.csv)，[9份来源](source_registry_m0.csv)，[5条原始发表累计指标](metrics_m0.csv)，公司财务细账 **NOT_ACQUIRED**；历史因果回归 **NOT_RUN**。

**唯一下一步：** 取得VOC历史年度收入/运营费/债务/分红（尤其1770—1800），并与荷兰国库军费区分；对1780战争冲击以前和以后建立营运现金流收缩的事件对照。

**本轮最强反例**：1603—1648年荷兰省债息支付占财政总支出比例从约12.59%增至38.38%，但名义战争支出也从约518万荷兰盾增加至约1041万荷兰盾；因此“债息上升必然导致同期名义军费下降”不成立。它**不能证伪反事实财政挤出**，也不适用于1780年前后的VOC财务压力。
