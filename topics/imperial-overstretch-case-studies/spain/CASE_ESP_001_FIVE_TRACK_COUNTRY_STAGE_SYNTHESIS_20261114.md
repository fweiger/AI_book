# CASE-ESP-001｜西班牙殖民帝国研究阶段总汇：五维度机制、核心反例与跨国比较出口

**2026-11-14 · 对象1492—1824 · 唯一[Issue #32](https://github.com/fweiger/AI_book/issues/32) · 现有[Draft PR #36](https://github.com/fweiger/AI_book/pull/36) · 上位[TOPIC-010 #30](https://github.com/fweiger/AI_book/issues/30)**

> **阶段决定**：西班牙作为五国比较的**首轮国家研究与已有发表财政数据描述性审计足以阶段收束**；不等于完成全部原始档案和因果验收。研究重点从无限扩充单笔银行票据/港口工资/圣多明各欠薪，切回「殖民资源→财政转移→战争动员与融资→产业转化不足→帝国政治退出」总体机制。上述箭头均为待区分的因果链，不是已经回归识别的一个总体估计。

## 1. 最初为什么选择西班牙？

这是对“拥有早期殖民财富就能转化为持续工业/军事霸权”的**负向对照**。西班牙拥有美洲主要银矿、跨大西洋贸易、帝国海军以及连接美洲多个王室国库的财政网络；但帝国战争与债务成本、各地殖民政治联盟和本土制造业竞争力的发展是不同结果。研究目的并非证明“所有帝国都因收入不足破产”，也不是证明“英国主动策划所有殖民战争”。

**需要回答的国家级问题**：
1. 贵金属和全球商品贸易以何种生产/强制劳动制度运作（A/B）？
2. 有多少财政资源**向欧洲王室转移**、有多少用于**美洲/加勒比内部防务**（B/D）？
3. 连续战争和金融承诺是否侵蚀国家继续动员的能力，何种证据与反证存在（C/D）？
4. 这种国际财富和国家财政能力为何**不能自动**变成制造业持续技术优势（E）？
5. 1808后政治合法性危机与地区独立，是否能区分于财政缺口（C/E）？

## 3. 几组最重要的实数：足够支持“国家画像”，不证明帝国净回报

### 3.1 新西班牙的汇款：有去往欧洲，也有去往其他殖民地

[已发表1720—1799十年均值完整表](remittance_decadal_m1.csv)源于 Martínez López-Cano（2022）Cuadro8、引用Marichal/Souto（2012），单位**历史名义比索/年均**：

|十年窗口|汇往卡斯蒂利亚|汇往其他殖民统治地 `situados`|合计|situados占比|
|---|---:|---:|---:|---:|
|1780—1789|1,655,605|6,170,565|7,826,170|78.85%|
|1790—1799|4,317,453|4,748,523|9,065,976|52.38%|

**意义**：1790年代输往卡斯蒂利亚的占比增加，但并不能把两个目的地的全部输出都称为“马德里纯利润”。当地防务和跨殖民维持是收入循环的重要组成。

### 3.2 1784—1820发表财政/贸易年度序列揭示战争期间不连续而非单调衰退

基于 Prados（2024）Tables6.2和6.4，均为**百万名义雷亚尔/年均**，完整[财政43年](fiscal_annual_prados_1778_1820_m2.csv)、[贸易43年](trade_annual_prados_1778_1820_m2.csv)，不是原始Simancas国库现金凭证：

|期间|输往本土的Indies款项|占重建财政总收入比例|西班牙本国产品向美洲出口|
|---|---:|---:|---:|
|1784—1792|85.56|11.54%|205.11|
|1797—1801|47.20|2.60%|54.40|
|1802—1804|268.00|20.46%|279.67|
|1805—1807|31.33|2.71%|43.67|
|1815—1820|0.00|0.00%|106.00|

**两条强反例**：①1797—1801受到冲击**但1802—04回升**，所以“不间断一条线崩溃”错误；②1815—20国库Indies款项记录为0却仍存在西班牙对美洲商品出口，故“失去对殖民地财政征税权＝立即失去美洲全部商业市场”也错误。原研究贸易地理份额存在1792/1827基期回填假设，1808财政零记录并非国家所有收入真的为零；不把跨窗变动归为孤立战争因果系数。

### 3.3 军费/政府债与金融脆弱性

- Barbier（1984）发表中央国库口径的**西班牙本土海军支出/中央总支出**：1784—92 **25.03%**、1793—96 **31.51%**、1797—1801 **14.32%**、1805 **7.66%**（详细[海军口径审计](M2B_NAVAL_FISCAL_AUDIT_20261114.md)）。下降不能断言债息完全挤占海军；海外舰队支出、陆军等并不在相同口径。
- 1811年Cortes公开1808年债务清单：粗计**7,194,266,839雷亚尔＋33马拉维迪**，相应年度**应付**利息义务**219,591,473雷亚尔**，**不是实际已付**。官方原页索引[西班牙众议院PDF](https://www.congreso.es/docu/blog/30031811-781.pdf)，该PDF曾仅文本取得，影像阅读受阻。
- Banco de San Carlos **1807年**银行账面王室债权约**217.3百万雷亚尔，占该银行313.4百万资产的69.34%**（西班牙央行1994公布的史学重建表）；该比率不能证明全部私人产业信贷实际被挤出。对该债权另存在166.4百万、125.653百万等不同会计口径，已归档**未解决**。
- 上述数据足以说明财政、国家信用和金融体系面临的**潜在约束**，不等于已求出1492—1824西班牙帝国**税收收益－全周期军事/治理/利息/行政成本**的净现值；全帝国ROI及偿债挤出因果 **NOT_IDENTIFIED**。

## 4. 先形成可证伪的西班牙国家判断

|候选命题|目前证据|最强反例与边界|结论级别|
|---|---|---|---|
|S-01 白银和殖民汲取为财政动员提供重要资源|美洲银矿、汞与劳动、国库地区汇款及对马德里款项的重建证据|一部分汇款用于其他殖民地守卫，不可全部当马德里净税收；不是所有美洲白银归王室|**支持，非利润计算**|
|S-02 战争融资、海运中断和债务义务使国家更脆弱|多轮战争冲击、1797—1801和1805—07汇款及贸易下降、1808高债务和银行集中|1802—04恢复；军费占比下降不必然来自债息挤出，海上战争/货币/国内税亦影响|**描述支持、因果权重未识别**|
|S-03 国家汲取能力越强，地方政治就一定越稳定|波旁改革作者回归估计提高部分财政征收|作者同时讨论精英抵制，印第安抗议与精英政治独立态度未必同向|**强版本受到反例挑战**|
|S-04 殖民资源财富可自动转化成持续制造领先|殖民规模与白银、王室财政能力早期扩大|加泰罗尼亚实际有产业发展；西班牙产业技术、工资、资金配置信息不充分|**自动转化的充分性被挑战，具体产业因果不足**|
|S-05 1808后退出完全由帝国财政破产造成|1808王朝合法性冲击与1810—20美洲政治军事变局|地方社会联盟/独立战争/国际军事因素和1808后地区区别大；失去税权后仍可做贸易|**财政单因果版本不能成立**|

**国家案例阶段性综合解释（非已识别因果定理）：** 西班牙把大量海外资源纳入一个军费、王室财政、跨殖民据点防务与政治统治相互交织的网络；随着军事冲击、税制改革及地方政治利益冲突叠加，这个体系的财政韧性和政治凝聚力受到挑战；而西班牙本土制造竞争力的发展不能仅用海外白银与王室收入解释。**帝国政治退出与工业化相对不足是两个相互关联、但不是同一个结果变量**。

## 6. 回到四国比较时，西班牙应提交哪些结果？ 

**只带四个可比较的命题，不搬运几十份国家账本**：

1. **资源—工业转化**：西班牙拥有银矿与帝国商品网络，但不能据此推断本土持续制造增长；与葡萄牙黄金/制造业激励、荷兰金融/机械锯木、法国科学院/制造转化做**机制对照**。
2. **殖民收益去向**：进入宗主国国库的税款≠美洲跨殖民防务`situados`≠私人商业利润；比较国必须使用相同的`会计主体×时间×单位`规则。
3. **战争与融资约束**：西班牙多轮战争和1808债务风险可作为国别财政韧性实例；不是“全帝国逐年亏损”的证据，也不该与英国/荷兰公司账本直接相加。
4. **政治退出独立于商品关系**：财政汇款断裂、主权变化、国际贸易联系仍可能不同步；与四国各自独立运动/公司破产/金融危机的差异做对照。
