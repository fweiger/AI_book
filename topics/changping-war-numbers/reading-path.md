# TOPIC-013｜先史料，后考古，再约束模型

**R1（优先）｜源头查证**：读[S01](sources.md)《白起王翦列传》；再核《史记》秦本纪、六国年表、赵世家、廉颇蔺相如列传、韩世家与《战国策》秦策三等，逐条提取40万/45万/60万的**原句、上下文和发生时间**。不把不同著作中相似数字自动视为独立旁证。

**R2｜现代争鸣**：已读[S02](sources.md)张广志2016论文；进一步合法寻找[S05](sources.md)宋裕1983、[S06](sources.md)舒咏梧1990、[S07](sources.md)王树新2007，按“质疑哪一个数字/作者自己估计多少/依据是什么/最强反对理由”整理，不先选赢家。

**R3｜考古底账**：以[S03](sources.md)政府规划为定位底稿，进一步核[S04](sources.md)1996发掘简报；分地点收集面积、深度、骨骼最小个体数MNI、创伤、生物考古断代、是否二次安葬。强调抽样偏差。

**R4｜历史约束**：可用[粮草敏感性框架](methods-logistics.md)提出“如果有45万则需多少粮”的条件命题，但必须引入独立亩产、运力、输送距离数据，不能由假设推回唯一兵力。

**R5｜横向比较**：不混用时代，先经清代实到军额档案核视频陈述，再看明军营额/实际援军/宣传数字。此步只讨论统计机制，不反证战国人数。

每轮输出：`Q-ID → C-ID → 来源定位 → 原文/估计/情景区分 → 最强反证 → 状态`。
