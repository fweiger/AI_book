## 我们究竟要回答什么？

《史记》记录白起“卒四十万人降”及“前后斩首虏四十五万人”。这些数字是否真指长平一役中被包围并投降的40万赵军？又能否推出秦赵双方在同一时点各有数十万战斗兵力？“坑杀”是否意味着40万人同时活埋？战术分割所用2.5万兵和5000骑兵能否反推赵军规模？

同一战争至少应分别核算：**战区最高同时在场人数、战役期间累计投入、主战部队、守备与后勤民夫、战斗死亡、被俘、投降、处决与实际掩埋者**。这些不能互相替代。

## 现有进度

**一手文本已初步核对**：《史记·白起王翦列传》记载四十万降卒、前后四十五万斩首虏、二万五千截后路、五千骑兵隔绝营壁；需继续与《史记》各篇、《战国策》的异文及年代关系交叉校验。

**学术论文完整阅读**：张广志《有关秦赵长平之战的几个问题》，《邯郸学院学报》2016，26(2):5–9，公开校方PDF；作者质疑40万降卒全杀并提出较低的估计，但所引的不同估计**不是学界已验证的统一数字**。

**官方遗址资料核读**：高平市《长平之战遗址保护规划（2024—2040年）》述1995年调查认定18处尸骨坑，永录一号坑约130多个个体；其余17处缺详细考古资料。2023年另记录23处骨骼暴露点，其中3处为普通墓葬。**不能用现存发掘个体数反推全部死者数量，也不能认定23处皆为独立的长平军人坑。**

**未核实**：视频给出的秦军60万、赵军45万同时投入、战国亩产范围、总人口、清代实际兵员等数据均无充分原始来源。清代类比不能替代战国证据。

## 当前最重要的结论边界

“有学者怀疑40万”≠“已证明只有10万/20万”；“出土约130个个体”≠“只杀130人”；“2.5万人截粮道”≠“最多只能围住2.5万人”；“《史记》同篇存在秦60万”≠“秦在长平有60万”。应把最强支持与最强反证并列记录。
