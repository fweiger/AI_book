# TOPIC-013｜粮草与人口情景模型（方法草案；不得冒充历史测量）

研究目的不是“算出长平一定只有几万人”，而是揭示**每个传统数字成立时必须满足的条件**，以及哪项考古或历史资料能驳倒这些条件。

## 一、统一变量与单位

- `N(t)`：t时点需要供养的军人数量；`N_peak`表示同时在场上限，`N_cumulative`表示长期累计服役人数，不能直接相乘。
- `r`：每名军人每天消耗的粮食（公斤/人/日，**待取历史文献估计范围**）。
- `D`：有该人数需要供粮的天数；**不等于上党争端全程**。
- `f`：送达率（运到营地的粮/离开生产区粮），范围(0,1]，依距离、方式与季节变化；视频“50%损耗”是**未经验证的假设**。
- `H`：人畜、征发随军、工事及盟友等额外支出，应单列，不能藏在每日士兵粮食里。
- `P`：总人口；`a`：可征人口比例；`c`：实际同时征用比例；必须考虑农业劳动和留守兵力。

## 二、计算

`前线粮食吨数 = N × r × D / 1000`。

`起运粮食吨数 = 前线粮食吨数 / f`（尚未计算牲畜、运输工人的口粮，不能据此得出完备总量）。

`兵员占人口比 = N / P`。如果人数包含民夫与主战士兵、或是累积人次，则该比率要重算，**不能把它直接视为壮丁征集率**。

## 三、纯演示情景（r=1.0公斤/日、D=180天、送达率f=0.5；均非经验证的长平史实）

| 假定同时供养人数N | 前线粮食/日 | 180天前线粮食 | 起运粮食（送达率50%） |
| ---: | ---: | ---: | ---: |
| 50,000 | 50吨 | 9,000吨 | 18,000吨 |
| 100,000 | 100吨 | 18,000吨 | 36,000吨 |
| 200,000 | 200吨 | 36,000吨 | 72,000吨 |
| 400,000 | 400吨 | 72,000吨 | 144,000吨 |
| 450,000 | 450吨 | 81,000吨 | 162,000吨 |

**注意**：以上只是可审计的乘法例子，**既不验证180天全员在场，也不验证1公斤配粮或50%到达率**；它是下限性的粮食账本示例，尚未加运夫自耗和马匹草料。不得以本表在Issue中报告“实兵10万人”等推定数。

## 四、下一轮真正需要的外部证据

- 长平时期秦赵人口与农田、可征籍、适龄男子比例：从历史人口研究抽不同口径，不将单一假设锁为真。
- 当时粮食生产：史书斛、石、斗、亩的地域/时期单位换算须先标准化；核净收成 vs 总收成、种子与税粮。
- 运粮：上党—河内等路线、河运与陆运、道路容量、车和畜力、驻军就地筹粮。
- 时间：战斗阶段、围困46日、此前驻屯阶段分别计算**时变人数N(t)**，不能用最高兵力乘以整场战争跨度。
- 反证：地方粮仓遗迹、粮运文书、同年代已证大型战役、地形瓶颈；不能只挑支持低兵力的材料。

## 五、证据与模型必须区分

模型能回答“若N=40万，需求有多高”，但若缺`P, r, f, D`可靠区间，无法回答“历史实际上N=多少”。文献存在夸大与生产条件困难可以共同成立；反过来，高动员成本也不证明没有高动员。
