# TOPIC-013｜九个独立研究问题

| ID | 待解核心问题 | 最小验收 |
| --- | --- | --- |
| Q01 | “40万降卒”“前后45万”“赵军45万”“秦军60万”分别最早出现在哪些文本？ | 原文、年代、篇卷、传承链和是否为同一来源 |
| Q02 | 战区同时在场、战役累计投入、被围降卒、非战斗人员如何区分？ | 按日期/兵种/口径生成独立表 |
| Q03 | 战争持续六个月、一年半、两三年的不同说法为何产生？ | 上党争端、主力交战和围困起止日期分层 |
| Q04 | 永录一号和其余遗址究竟证明了何种死亡方式与人数下限？ | MNI、地层、埋葬方式、断代、样本来源 |
| Q05 | 秦赵可征适龄男子及农业劳动力的数量级如何估计？ | 至少三组学术口径及敏感性，不用确定人口假数 |
| Q06 | 不同人数、战役长度、粮运效率的净粮草可行域在哪里？ | 可复核公式、单位、假设表、情景范围 |
| Q07 | 2.5万截断后路与5000骑兵割营是否能够对总兵力提供约束？ | 地形、道路、补给通道数量与反例 |
| Q08 | “40万”形成是战报统计、政治修辞、后世强化还是混合？ | 史料谱系和其他战役相同作者数字表现 |
| Q09 | 明清军额的宣传数、作战主力、后勤、累计动员有什么可比关系？ | 至少一明一清案例的原始档案，禁止朝代直接套用 |

每题报告须包含：来源定位、哪部分是史书记述、哪部分是学者推论、反例与未解证据。

## 第二轮新增约束

Q05人口必须区别独立证据与从《史记》《战国策》军额推回的推算；Q02同日主战/辅助/累计人次分列；Q06用兵员日和路线送达率而不是单次战役时长；Q04每坑MNI、古今点位去重、埋葬层与未发掘区域分开；Q08对照张广志2016的怀疑与吴磊佳2024对40万统计口径的支持；Q09清代比较须同年同时同案同统计口径。

## 第三轮增加的识别标准

Q07：测试李冀侯甬坚2023 **2.72E最小兵力**模型，要求战线E有地理物证、攻方同一阶段At、20个案例原始完整口径；将下限与实际人数视为不同概念。

Q06：引入里耶秦简士伍`2/3斗/人日`与前344年商鞅标准方升`202.15ml`，区分粮食**容量**与重量、统治年代、实际角色及运输自耗。

Q04：南王庄2020疑似骨层与宋金明重新收骸的地方记载需溯源，必须先做1995/2020/2023点位去重与真正MNI再谈整体规模。

Q05：增加武库作为可能限制军队规模的装备维度，需**出土铭文年代及库存数量**；行政制度不能直接替代规模测量。
