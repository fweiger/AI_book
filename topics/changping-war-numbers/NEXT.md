# TOPIC-013｜下一轮可执行任务

研究总入口：[Issue #64](https://github.com/fweiger/AI_book/issues/64)。本专题尚无已证实的唯一人数答案。

**P0 史料**：逐句梳理《史记·白起王翦列传》《赵世家》《廉颇蔺相如列传》《秦本纪》《六国年表》以及《战国策·秦策三》，确认40万、45万、60万首见与相互依赖；标注“杀/阬/埋/坑”动词语义。

**P0 考古**：取得[S04](sources.md)1996年《文物》发掘简报原刊，用出土骨骼个体清点、伤痕和地层特征核[S02](sources.md)转述。搜集2023调查原始报告并去重坑位。

**P1 量化**：采集可核的人口、亩产、运力、里程、马匹用草、运输劳力与持续时间区间，跑[methods-logistics.md](methods-logistics.md)的敏感性矩阵；必须保留至少一组允许传统大军数的对照参数。

**P2 明清对照**：准噶尔、雅尔哈善南疆、两次清缅战争、年羹尧青海与明代一场典型战役，逐一找到同期军报/档案，不用影视宣传的军额和实际参战人数简单相减。

**验收**：完成1份古籍出处矩阵+1份考古MNI证据表+1份透明情景模型+至少1个对“数值夸大说”的强反例，再允许更新C-ID状态与专题版本。

- [论文交叉辩证](research/2026-11-15-academic-debate.md)：吴磊佳2024与张广志2016逐条互驳及同源证据标注。

## 第四轮全文审查后的优先行动

1. 取得靳生禾/谢鸿喜1998年原地图的坐标与逐路段遗迹测绘；检验125km是否应作为同一时点五人纵深战线。
2. 获取蓝永蔚1979《春秋时期的步兵》110–125页原文，复核五人纵深、1.84m间距是否适用战国围困整环。
3. 审查白起秦卒死者过半的时序，不能无条件将瞬时34万乘2得累计大于68万。
4. 逐条回源20战例表1，第18例安市高丽救援15万是否与唐攻城长度混用优先核查。
5. 把即时秦围军口粮容量、赵人口和战区屯粮独立上限与攻方最低兵力比较；无法定史料参数时保留范围。
6. 赵军40万降卒被杀属于独立问题，继续以1996原始考古简报及秦赵人口簿、战国史料系谱核查。

## 第六轮新增精确验收

1. 核2026-10太行日报七段长度和地名，补七段经纬坐标、起止两向差、分段年代、秦/赵方别。需要特别核实北山村北0.32km与西北0.32km、泉头村北0.5km与西北0.38km是否相接；**不能在GIS强行拉直串联**。
2. 将高平2024保护规划的赵空仓岭/丹河/百里石三线，与李2023秦最后125km围困圈分层；核靳谢1998/2013原地图来源与1960年代约120km百里石历史长城来源，不能因为数值相近就视同。
3. 核蓝永蔚1979五人纵深与1.84米的原书段落，验证是否用于战国太行山围困全环，而非一般阵型。
4. 优先还原《三国志》寿春26万游军、《晋书》广固4万石挺济师、《资治通鉴》太原四路10万、睢阳13万与表30k的具体日期，已有9个有源头疑点战例，剩余11个逐一核。
5. 继续秦赵人口、粮仓、装备、46日时序的独立上下限；**赵降卒40万被杀须独立考古与古籍证据**。
