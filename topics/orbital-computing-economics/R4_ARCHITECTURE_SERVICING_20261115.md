# TOPIC-012 R4：大型可维修轨道算力站 vs 分布式整星替换（2026-11-15）

> 唯一规范研究入口：[AI_book Issue #60](https://github.com/fweiger/AI_book/issues/60)；现有 [Draft PR #61](https://github.com/fweiger/AI_book/pull/61)。**状态：初次数量化情景已运行 / 未完成工程成本核准 / 供应商报价未取得**。本轮以是否值得在轨部署算力的经济命题为核心，不因为某个机器人已经发射，就声称大型LEO计算设施已具备低成本可维修性。

## 0. 执行摘要

**技术证据：** 有经过实际执行的GEO卫星服务（MEV-1/2推进与姿态寿命延长）、LEO交会/磁性捕获（Astroscale ELSA-d）、近距离非合作目标检查（ADRAS-J）；DARPA/SpaceLogistics 2026-07-21发射了具有机械臂的GEO MRV，但当期未查到可核实的**LEO大型GPU模块更换的真实客户任务和合同价**。NASA OSAM-1在2024年停止，反证大规模服务技术并非成熟即用。GAO 2025确认自动化ISAM服务尚未普及。

**商业结论：** R4按1MW总算力比较两个相同IT输出的架构。研究情景在$100/kg比例运费下得到集中式机器人维修约**$3.37/贴现有效GPU小时**，分布式整星替换约**$5.47**；对应$1,500/kg情景则约**$4.91 vs $9.36**。二者都高于沿用R2假设的地面$2.365/GPU小时。**不证明轨道算力盈利，不证明集中方案现实已优。**

**方法学修正：** R3的“2%年度损坏→每年专属一发”是刻意设定的固定维修节奏而非正确的随机任务期望。若定义10个可独立故障节点、每节点一年故障概率2%，则一年至少1个节点出故障的概率 `1-(0.98)^10≈18.29%`。在无备件缓存、年度合并运送、全部节点同轨、单次满足运力的**附加假设**下，20年全生命周期专属运输期望发次 = 初始1 + 第4/8/12/16年4次升级 + 其余15年的故障概率期望 `15×18.29%≈2.74`，共**7.74次**，**不是确定的7.74次火箭，也不是保证可以按此排班**。

## 2. 统一情景边界

| 字段 | 情景值 | 证据性质 |
|---|---:|---|
| 系统计算规模 | 1MW IT，10个100kW单元 | 自定义模型设定；非真实制造配置 |
| 参考轨道截面 | 550km圆轨道、β=0° | 沿用R3几何截面，不是全年真实轨道 |
| R3整体初始质量 | 52.95吨 | NASA小航天器组件比功率和BCG散热面积代理值衍生，非实物 |
| R2/R3原始制造成本 | $85.86M/1MW | 全为R2组件价格**人工情景**，不是公开合同 |
| 其中IT更换部分质量/制造 | 5吨/$30M | 人工情景 |
| GPU 1000个等效单元 | 700W、IT功率70%、利用率80% | NVIDIA的700W规格可查；其余为假设 |
| 单模块故障概率 | 2%/年 | **人工设定**；代码使用指数危险率`-ln(0.98)`准确映射年概率 |
| 计算整体有效系数 | 0.873 | 0.97轨道可用率×0.90性能保持；仍需真实验证 |
| robot cost/mass | 初始$20M/2吨；每年维持$0.3M，每次出勤$0.5M | **人工设定，无法报价验真** |
| 10颗分布式卫星额外平台费 | $0.5M/颗，额外年度运营$0.6M | 人工设定；不包含全部独立太阳翼/通讯协议差异 |
| 发射运费 | $100/kg、$1500/kg比例运费，或$25M/100t未来整发 | 均是对照/视频未来情景，**非可下单报价** |
| 统一财务时点 | 20年、8%实质贴现、年末运营费用 | 情景；地面沿用R2 `$2.365/有效GPU小时` 研究对照 |

- `serviceable_hub`：1MW中心与2吨服务机器人初始发射；4年一次只换5吨IT模块；年度小故障可在有任务时按需更换IT，而保留PV/储能/热控等系统，**但机械臂实际能否安全更换GPU未证实**。
- `replaceable_fleet`：10颗100kW同轨卫星，在计算单元不可修的设定下，4年换整批卫星、年度模块故障用整星替代，**不需要轨道现场维修机器人**。这一架构牺牲太阳翼/散热/控制总成、换取更小单体故障域；适合检查“整星替换是否会消耗掉廉价运输的优势”。
- 两种年度方案的维修/补发都是**故障发生后，在年度窗口恢复**；无年度维修方案为4年一次计划性升级，期间允许性能衰减。近似指数存活函数的逐年平均：`exp(-λ*age) * (1-exp(-λ))/λ`。
- 年度故障运输只在**至少发生1个独立节点故障**时收费：比例运价按期望重量线性收取；专属整发费按Binomial事件概率的期望成本收取。**未建共享发射可用舱位和实际任务排期**。
- 本版本**没有把中心平台灾难性失效的期望维修成本计入**；结果附带示意共因失效概率，但共因会改变排序，应作为下一轮硬边界，而非隐式忽略。

## 3. R4已运行结果（20年现值/贴现有效GPU小时）

| 运输机制 | 维修政策 | 中心$每GPUh | 分布式$每GPUh | 中心期望专属发次 | 分布式期望专属发次 |
|---|---|---:|---:|---:|---:|
| $100/kg比例 | 年度维修/替换 | 3.37 | 5.47 | — | — |
| $100/kg比例 | 每4年集中替换 | 3.37 | 5.37 | — | — |
| $1,500/kg比例 | 年度维修/替换 | 4.91 | 9.36 | — | — |
| $1,500/kg比例 | 每4年集中替换 | 4.94 | 9.17 | — | — |
| $25M/100吨专属整发（纯未来设想） | 年度维修/替换 | 5.09 | 7.03 | 7.74发* | 7.74发* |
| $25M/100吨专属整发（纯未来设想） | 每4年集中替换 | 4.54 | 6.38 | 5发* | 5发* |

`*` 发次为质量上界允许条件下的**概率期望/整数确定刷新**，不是可购买的确定发次，且不包括延期与失败补发。分布式和中心均沿用相同的危险率与更新时点；分布式整星更换的质量与制造成本明显更高。年末20年终点不进行没有经济服务价值的新增换新。

**反证条件**：若集中式由于共享总线、热控、连接器或机器人风险导致的额外有效GPU小时损失足够高，可能逆转上述排序。在$100/kg年度维修情景中，若中心的**额外有效小时数减少38.45%**且不增加分布式损失，单位成本刚好与分布式持平；$25M整发情景对应约**27.55%**的额外中心有效小时损失阈值。这是保持成本固定的简单比率阈值，并未由真实共因失效分布校准。

在研究假设“中心全系统突然不可用概率1%/年”和“每颗分布式卫星独立出现不可用概率1%/年”下，整个1MW丢失的**边际事件概率**可分别为1%和 `0.01^10`（只有真正独立时才成立）。这不是一个真正意义上的实际年度停机概率估计；若分布式共用光伏、电源、数据下行链路或软件版本，则可能存在相关失效，独立假设失效。该尾部风险也尚未进入现金流分母与损失模型。

## 4. 本轮模型纠偏和局限

**R3维修任务口径修正：** 固定每年发一次属于保守的确定性合同调度场景。R4使用10个独立故障事件的二项概率，但这只修正了“故障事件计数”，未证明可以合单发射、无维修等待、或机器人始终在线。如果客户要求最大停机时长，故障到交付窗口延迟可能显著改变收益和可用率。R4不等价于全寿命随机蒙特卡洛。

**架构分界**：中心修理IT、分布式整星更换，二者功能目标相同但可更换层级不同。这就是所需比较的经济学决策，而非两款真实厂商产品。若分布式节点也可在轨更换IT而不换PV/散热，则它逐步变成分布式**可维修**架构，成本排序可能改变；若中心热控/电源无法修复，中心成本可能更高。

**需要补齐的真实证据**：同轨LEO用户的机器人模块更换执行记录；机器人寿命、一次服务报价、工具通用性、对接接口、轨道转移燃料；60吨级模块化阵列与散热器可部署性；火箭具体轨道下的可用载荷；H200及IT系统在轨有效吞吐与寿命；共同故障/网络限制造成的停机分布。
