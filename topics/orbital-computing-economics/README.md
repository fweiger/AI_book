## 核心问题
**在什么工程与经济条件下，太空数据中心比地面数据中心更有价值？特别是：发射成本何时不再是决定性障碍，剩余瓶颈是什么？**

研究对象并非笼统的“太空有太阳能”。先识别架构：
1. A（主线）：在轨 GPU/CPU + 轨道光伏 + 轨道散热 + 数据传输。
2. B（对照）：轨道光伏发电并向地面送电，计算中心仍位于地球（不同系统，不可混算）。
3. C（特例）：卫星观测数据在轨处理，减少数据下传与时延。
4. D（可选扩展）：计算废热用于太空温室/其他热应用。新增设施质量与风险必须计入，不能把全部废热按零成本变成收益。

## 研究闭环
```text
工作负载 / 算力效率
   ├── 太阳光伏 / 储能 / 功率电子 → 能量闭合
   ├── 芯片与系统功耗 → 废热 → 散热器面积/质量
   ├── GPU/太阳翼/散热器/通信/屏蔽/结构 → 在轨总质量与体积
   └── 目标轨道、发射次数、运力装载和发射价 → 建造成本
                                        ↓
                        可靠性/故障/替换/退役
                                        ↓
                         全周期TCO与可用计算量
                                        ↓
                        对照地面TCO、专属应用价值
```
**禁止只比较“发射价 vs 电价”而跳过设备质量、寿命和有效算力输出。**

## 已知与未知
- **确定物理事实**：真空中不存在通常意义上的对流散热，需通过辐射向外排出能量；对 MW/GW 规模的热排散，面积、质量与姿态成为关键系统量。
- **历史估算，不是工程验证**：350K 的 1MW 理想单面散热面积约 1175m²；298K、ε=0.9的 2GW 理想单面面积约 5km²。
- **待求证经济性**：何时能做到 `$/effective GPU-hour` 优于或至少匹配地面；某些卫星原生任务价值可由链路成本减少而非价格平价实现。
- **缺失**：历史会话完整URL、当年发射成本模型原始参数（如存在）、经工程认可的质量预算、故障分布、GPU寿命和规模化发射的实际合同价格均为 `NOT_RECOVERED/UNKNOWN`。
