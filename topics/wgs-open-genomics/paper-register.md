## 不能混淆的证据层级
- **方法论文**：说明软件可以实现什么，不等于临床有效；要求软件 release、参考构建与输入格式。
- **GWAS / PRS 论文**：人群上发现统计相关或建立预测模型，不等于一人的 WGS 能复现 GWAS；个人仅可按已发布、匹配祖源的模型进行评分，必须查外部校准。
- **临床指南**：指向临床实验室确认、专业解读和风险沟通；并非消费者报告即能作诊断。
- **干预型研究**：随机对照试验优先于单纯 SNP 相关用于评估“按基因制定饮食/睡眠干预是否有效”；P020 是应被保留的负结果。

## 如何回答“这个维度一共有多少论文”
目前只能报告**本专题已实际纳入并去重的论文数**。全球相关文献数必须固定检索日期、检索式、题录数据库（PubMed/Europe PMC/GWAS Catalog/PGS Catalog）、纳排标准、重复 DOI 处理与版本；否则「某领域有多少篇」是不可复现的广告式数字。

每篇后续研究登记字段：`P-ID / DOI / title / publication_date / study_type / samples_N / ancestry / training_vs_validation / assay / genome_build / phenotype / method / data_access / code_repo / result / negative_evidence / replication / fulltext_status`。
