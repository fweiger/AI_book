# TOPIC-017｜问题驱动阅读路径

1. **Q01/Q02（技术底座）**：[Sarek 2024](https://doi.org/10.1093/nargab/lqae031) → [GATK Best Practices](https://gatk.broadinstitute.org/hc/en-us/articles/360035894711-About-the-GATK-Best-Practices) → [GIAB](https://www.nist.gov/programs-projects/genome-bottle)。先证明可计算和误差边界。
2. **Q03/Q04（父系与母系）**：[Yleaf 2018](https://doi.org/10.1093/molbev/msy080) → [Y-LineageTracker 2021](https://doi.org/10.1186/s12859-021-04057-z) → [Haplogrep3](https://pubmed.ncbi.nlm.nih.gov/37070190/)。研究“分支”而非预设“名人家族”。
3. **Q05/Q06（亲属与人口史）**：[ancIBD 2024](https://doi.org/10.1038/s41588-023-01582-w) → [AADR](https://doi.org/10.7910/DVN/FFIDCW)。先分析样本与偏差，再谈历史叙事。
4. **Q07/Q08（可行动健康）**：[ACMG/AMP 2015](https://doi.org/10.1038/gim.2015.30) → [ACMG SF v3.3](https://doi.org/10.1016/j.gim.2025.101454) → [PharmCAT](https://pharmcat.clinpgx.org/)。研究建议应交专业人员确认。
5. **Q09/Q10（复杂性状与边界）**：[PRS 跨人群方法 2024](https://doi.org/10.1038/s41576-023-00637-2) → [睡眠节律 GWAS 2019](https://doi.org/10.1038/s41467-018-08259-7)。区分可统计相关与实际可预测性。
