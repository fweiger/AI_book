# TOPIC-017｜研究问题与分层验收

| Q-ID | 核心研究问题 | 关键输入 | 初步可检验结果 | 不可直接推断 |
|---|---|---|---|---|
| Q01 | 30×/40× WGS 的有效覆盖率是多少？厂商交付可复用吗？ | FASTQ/CRAM、质控、reference | mean depth、callable fraction、Q30、dup rate | 40× 不保证所有 chrY/重复区都 40× |
| Q02 | SNV/Indel/SV/CNV/STR 能检出多少、漏掉多少？ | WGS、GIAB truth sets | precision/recall，区域分层错误率 | 统一单一准确率覆盖全基因组 |
| Q03 | Y-SNP/Y-STR 可重建何种父系树？ | chrY BAM/CRAM/VCF + 版本树 | 末端分支、相反位点、未知区间 | 具体姓氏/名人祖先必定成立 |
| Q04 | mtDNA 可重建什么母系支系？ | mtDNA VCF/reads | 单倍群、私有变异 | 全部母系亲属的完整历史 |
| Q05 | 近代家族与常染色体亲缘能检测到什么？ | 两人以上授权样本 + phasing | IBD 长度/亲缘概率 | 只用单人数据锁定未知亲人 |
| Q06 | 古 DNA 如何与现代人对应？ | 古样本元数据、AADR、参考人群 | 单倍群/群体模型/限定关系证据 | 共祖等于直接祖先、古代人等于现代族群 |
| Q07 | 疾病相关变异是否可医学解读？ | 优质 VCF + 表型 + ClinVar/ACMG | 可审查候选变异与证据 | 自动确诊/排除疾病 |
| Q08 | 药物基因组学能提供哪些候选用药信息？ | PGx 位点与 star allele、CPIC | diplotype/phenotype + 指南引用 | 自主改剂量或停药 |
| Q09 | PRS、睡眠、营养等复杂性状能预测多准确？ | 外部 GWAS、LD、祖源校准与表型 | 可重现评分/分组统计，置信区间 | 个体具体时间/食谱的因果确定性 |
| Q10 | 哪些分析超出标准短读长 WGS？ | 与长读长、RNA、甲基化、临床测量比较 | 盲区登记与后续检测需求 | WGS 包含全部组学/当前生理状态 |

**证据等级**：E0 GitHub README/官网可见；E1 原始论文/标准读到且方法与条件明确；E2 公共数据真实运行复现；E3 交叉验证；E4 临床证据/确证。不存在 E2/E3 自动升级 E4 的规则。

**注意**：本研究不依赖消费 WGS 后得到的“健康报告项目数”。先审查原始数据、变异调用、参考数据可用性。
