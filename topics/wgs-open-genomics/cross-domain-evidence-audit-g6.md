# TOPIC-017｜G6 D05/D11/D13：现代亲缘、睡眠与运动遗传学横向证据审计（2026-11-21）

> 本轮目标沿用 [AI_book Issue #72](https://github.com/fweiger/AI_book/issues/72)：**个人 WGS 数据质量 → 论文实际研究设计/证据 → 可以分析到的深度 → GitHub 软件/许可证/输入输出**。基于部分原始论文全文、期刊页面、PubMed 摘要及 GitHub 官方 README；**未运行任何个人/公开样本、未形成临床结论**。
>
> 核心结果：**D05 的 IBD 必须有其他样本才能证明人际亲缘；D11、D13 的 GWAS/PRS 是人群统计，不能从一个人的 WGS 推出精确作息、训练成绩或个体训练处方**。

## 1. D05｜常染色体 IBD：亲缘与个人基因组的真正边界

### 原始方法论文与实际输入
- **原登记 P008**：[Zhou, Browning & Browning 2020, *AJHG*, DOI 10.1016/j.ajhg.2020.02.010](https://doi.org/10.1016/j.ajhg.2020.02.010)：`hap-IBD` 在**经过相位（phased）的群体基因型**中检出 IBD，论文报告针对大型 UK Biobank 数据上的 2–4 cM 短片段检测效果。**此 2–4 cM 的论文能力不是单人寻亲灵敏度，也不保证每段 2 cM 都是可信近亲证明**。
- **[browning-lab/hap-ibd](https://github.com/browning-lab/hap-ibd) 官方 README**（核查 blob `58dc9f3d301e32ee91b7d5df280455025582e04f`）：输入**已相位 VCF**，全部记录需有 GT，**不得有缺失等位基因**；另需与 VCF 染色体命名和参考版本相符的 **cM genetic map**。默认 `min-output=2.0` cM。输出 Log、IBD 片段、HBD 片段，含两个样本及单倍型编号、位点区间。**Apache-2.0**（README License）已核。
- **[chrchang/plink-ng](https://github.com/chrchang/plink-ng)**：VCF→PGEN/PLINK 数据规范化、基本 QC、样本间亲缘统计，官方 README 可核 **GPLv3（PLINK 1.9/2.0）；pgenlib LGPL 分组件**。它不是 hap-IBD 的相位算法，不能仅因载入一个人 VCF 就构建多人族谱。

### 个人 30–40× WGS 的能力判定
1. **单人可完成**：常染色体基因型/QC、部分连续纯合片段（HBD/ROH）识别及与已有公开祖源位点匹配；**不能凭空生成第二人的 IBD**。HBD 是本人两条单倍型的同源片段统计，**不是“已经找到亲戚”**。
2. **需要他人数据**：至少两位明确授权者，且统一 GRCh37/38、ref/alt allele、phasing、缺失位点、SNP density、genetic map，才能运行 IBD 并估计其分布。多对多远亲匹配更要求**合法、足够样本量的已比对人群库**。
3. **推断上限**：IBD 片段长度分布能统计推断近远关系或共享祖先程度，但短片段假阳性和祖源背景 IBD 会影响解释；**IBD 不会输出祖先姓名或某人确定是某代的堂亲**。精确谱系需双边授权基因样本与民事/史料独立验证。
4. **数据门槛**：全基因组平均 40× 仅是 SNV 基因型可用性的一个条件；若交付只有 variants-only VCF，必须按共同位点完整基因型建立相位集；不能无依据将缺失记为纯合参考。确认已有 imputed/phased 参考集是否允许访问与传播。
5. **复现门槛（未运行）**：至少一个合法公开多样本相位基因型集，固定样本数量、genome build、genetic map、IBD 参考真值或已知亲缘、长度分层 precision/recall 与最小标记密度；**绝不把随机相似当近亲匹配结果**。

## 2. D11｜睡眠、晨晚型与睡眠时长：同为遗传性状，证据体系不同

### 研究论文及样本口径
- **P019 已登记**：[Jones et al. (2019), DOI 10.1038/s41467-018-08259-7](https://doi.org/10.1038/s41467-018-08259-7)：**697,828 人**晨晚型研究，主要为 UK Biobank **449,734** 欧洲祖源与 23andMe **248,098** 欧洲祖源 self-report；发现 **351** 个 loci；在 **85,760** 佩戴活动设备人员中，两端 5% 遗传晨型分数人群的平均客观睡眠时间差约 **25 分钟**。**群体平均差异不是对一个人的作息预报**。
- **新登记 P037**：[Dashti et al. (2019), DOI 10.1038/s41467-019-08917-4](https://doi.org/10.1038/s41467-019-08917-4)：UK Biobank **446,118 欧洲祖源**，self-reported sleep duration、**78 个相关 loci**，并在 CHARGE **47,180** 人外部信号检验及加速度计相关措施中研究。它研究“睡多久”，与晨晚型不是一个 phenotype。
- **新登记 P038**：[Portability of PRS for Sleep Duration, Insomnia and Chronotype, (2023), DOI 10.3390/clockssleep5010002](https://doi.org/10.3390/clockssleep5010002)：芬兰 **FINRISK 26,229 + Health 2000/2011 7,264 = 33,493 人**；检验由大型欧洲祖源 GWAS 建模的 PRS 在其他芬兰 cohort 的表现；**芬兰人群复现不能据此证明东亚祖源绝对风险校准准确**。

### GitHub 可复用实现
- **[PGScatalog/pgsc_calc](https://github.com/PGScatalog/pgsc_calc)**：已有 T32，可从公布的 PGS Catalog 权重文件计算评分并以参考人群归一化，Apache-2.0；官方 README **直接说明普通 WGS variants-only VCF 尚不支持**，需要构造完整、兼容的样本基因型/部分 gVCF 转换，并验证评分位点覆盖、`match rate`、参考 genome build/strand。
- **[chrchang/plink-ng](https://github.com/chrchang/plink-ng)**、**[privefl/bigsnpr](https://github.com/privefl/bigsnpr)**：常规基因型/PRS 运算底座，但**未找到针对个人 WGS 的临床级“优化睡觉时间开源引擎”**。该领域目前的 T28/T31/T32 是通用方法，不算已经完成睡眠专项校验。

### 研究能力分层
- **L1 可计算**：预先选定的 GWAS SNP 是否真正可判读；若有许可且祖源相符的已发表 PGS，计算相对倾向与缺失率。
- **L2 需外部模型/人群**：一人的遗传分数在相应 reference population 的相对分位、祖源校准、表型定义与开发/验证重叠检查。
- **L3 需个人表型**：连续睡眠日志、可穿戴设备、工作班次、光照、咖啡因、用药、年龄和疾病相关信息，用于检验自己的实际睡眠行为，但这不是重新验证 GWAS。
- **L4 不能由单人 WGS 证明**：个人应该几点入睡、最佳睡眠时长、是否会失眠或确诊睡眠障碍。晨晚型、时长和失眠应分别评分及报告，不合并成“睡眠基因分数”。
- **负证据/适用性**：Jones 的 PER3 关联位点对客观睡眠时点的平均影响可以远低于个别家族单基因病例的极端睡眠相位改变；这是不能拿某 SNP 决定个人睡眠时钟的直接提醒。

## 3. D13｜运动、体质和训练反应：活动习惯 ≠ VO₂max 训练效果

### 关键论文和可迁移性
- **P039**：[2022 *Nature Genetics* 多祖源身体活动 GWAS, DOI 10.1038/s41588-022-01165-1](https://doi.org/10.1038/s41588-022-01165-1)：**51 项研究、最多 703,901 人、99 个 loci**，主要 phenotype 为 self-reported leisure MVPA、screen time 和久坐行为；这与个人肌肉力量/短跑/有氧训练反应不同，也不是“运动天赋评分”。
- **P040**：[Bouchard et al. HERITAGE 2011, DOI 10.1152/japplphysiol.00973.2010](https://doi.org/10.1152/japplphysiol.00973.2010)：**473 名**久坐白人、99 个家庭、**20 周**标准化训练，检测 **324,611** SNP，拟合 **21 SNP** 集合在研究样本中解释 **49%** 的 VO₂max 响应方差；**49% 属于样本内统计模型，不是外部验证精度、不能直接据此预测某个人训练增长 49%**。原文呼吁大规模复现。
- **P041**：[Predict-HIIT (2021), DOI 10.1186/s12929-021-00733-7](https://doi.org/10.1186/s12929-021-00733-7)：多中心训练反应 GWAS **n=507**，含 HIIT/SIT/连续训练方案；尝试 SNP/PRS 和独立验证，作者明确指出基因预测对循证运动处方的可靠性尚待扩大样本复现。

### 实际 GitHub 代码
- 现有 **PLINK2（T28）、bigsnpr（T31）、pgsc_calc（T32）** 为基因型/评分通用工具，而非专门对“运动表现/训练最佳计划”完成已发表临床验证的开源包。
- 即便个人 WGS 的 21 个旧 SNP 全部可调用，也**不能直接继承 HERITAGE 的 49% 模型解释率**：外部验证、祖源、训练干预强度、性别/年龄、生活方式与表型测量误差都影响泛化。
- 研究方向需要分成 `活动行为`、`身体素质现状`、`有氧响应`、`肌肉增量` 等具体表型，逐篇寻找真实可复用权重，不把任何一项混称“运动基因”。

### 研究深度与失败门槛
1. L1 个人 WGS 可判读旧报道 SNP，建立等位方向与缺失标记（不是训练处方）。
2. L2 只有具祖源和表型匹配的公开模型时才生成学术用途 PGS；不同论文模型不能合成一个所谓“健身天赋指数”。
3. L3 若已有客观训练前后 VO₂max/力量/速度与训练量、依从性、睡眠饮食表型数据，才可做真正个体变化评价。
4. L4 需随机/对照、重复检测、外部祖源验证和临床医学安全评估，才能讨论按基因优化训练是否有增量效果。**目前 L4 无可支撑交付**。

## 4. 这轮新增“从论文到代码”的审计结论

| 方向 | 当前最关键数据质量门槛 | 可沿用源码 | 单人 WGS 可以达到 | 科学上限/禁止推断 |
|---|---|---|---|---|
| D05 | 多人授权、phased GT、无缺失等位、同参考和 cM genetic map | hap-IBD（Apache-2.0）、PLINK2（GPLv3） | 单人 ROH/HBD；有第二人时才可做 IBD | **IBD 不产生具体祖先姓名、单人不能认亲** |
| D11 | 评分位点 callable、模型 ancestry、variant match rate、外部 sleep phenotype | pgsc_calc/PLINK2/bigsnpr | 公开模型允许下的晨晚型或时长倾向 | **25min 是人群两端平均差异，非个人可预测钟点** |
| D13 | SNP/LD 与模型 build 一致、训练前后表型、祖源适配 | PLINK2/bigsnpr/pgsc_calc | 部分性状有 GWAS 权重时可学术评分 | **703901 人的活动行为 GWAS 不是训练反应预测；样本内 49% 不代表外推效力** |
