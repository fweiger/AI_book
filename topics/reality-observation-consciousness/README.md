## 不要预设的结论

- **纠缠 ≠ 超光速传信 ≠ 宇宙具有意识**。
- **观察者的心理经验 ≠ 量子实验的测量过程**。
- **哥德尔定理 ≠ 人脑不可能是可计算系统的证明**。
- **微管是细胞结构 ≠ 微管产生意识已被证实**。
- **某种理论在哲学上优美 ≠ 已得到独立经验验证**。
