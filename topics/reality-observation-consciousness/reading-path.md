# 五条跨书精读路线

> 采用“找到核心问题 → 跳读相应章节 → 逐段复核 → AI 交叉讨论 → 更新图谱”。无需按照出版年份或书单逐本读完。章节定位为公开目录级；不同版本的分节和译名需要二次核实。

## 路线 A · 整体与分割（建议第一轮）

**问题：世界的对象边界是绝对的，还是我们描述整体过程的工具？**

1. B001《整体性与隐缠序》第1–3章：语言、碎片化与过程。
2. B001 第6章 Part B：隐秩序和显秩序的核心论述（**最高优先级**）。
3. B002《不可分割的宇宙》第15章：量子理论与隐秩序的联系。
4. B001 第7章：关于意识的延伸；注意区分设想、比喻与可检验模型。

**输出**：W1/W2/W3/U3 的定义及层次比较；检查“墨水实验是否证明隐秩序”的跳跃。

## 路线 B · 量子测量能否不依赖意识

**问题：为什么测量获得确定读数？是否真的需要主观意识？**

1. B002 第5–7章：测量、物理过程、非定域性（**最高优先级**）。
2. B004《皇帝新脑》第6章：量子测量的概念难题。
3. B005《心智的阴影》第5–6章：另一种客观还原设想。
4. 区分“量子诠释不同”与“实验已经排除某一主流解释”。

**输出**：U2 ↔ S2 的理论对照，并把“意识坍缩”标为独立待证命题。

## 路线 C · 观察者与自我

**问题：我们如何把思想中的观察者当成独立实体？**

1. B003《最初和最终的自由》：“思考者与思想”“觉察”“论命名”。
2. B001 第1–3章：语言分类与碎片化。
3. B002 第6章：把物理测量语境中的“观察”与心理觉察明确拆开。

**输出**：K1/K2/K3 和 W1 的概念边界；建立一条“禁止直接等同”关系。

## 路线 D · 哥德尔、计算与理解

**问题：算法极限足以证明人类意识不可计算吗？**

1. B004 第2、4章：图灵计算、形式证明与数学洞见（**最高优先级**）。
2. B005 第1–3章：彭罗斯如何强化原有论证。
3. 复核哥德尔定理的前提：形式系统有效可枚举、足够表达能力与一致性等。
4. 阅读数学逻辑反对观点，区分数学结论与哲学推论。

**输出**：E1 → S1 的完整前提链，以及反对观点和开放问题。

## 路线 E · 微管、客观还原与意识

**问题：假说究竟提出了什么可证伪的经验预测？**

1. B004 第8、10章：彭罗斯为何寻求新物理。
2. B005 第5–8章：客观还原、神经系统、微管与意识。
3. 查证后续 Orch OR 文献与批评，不将微管的存在等同于意识机制获证。

**输出**：S1/S2/S3 的假说清单、独立预测、可反驳条件与证据等级。
