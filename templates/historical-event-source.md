# 历史史料证据卡（EV-ID）模板

> 无真实来源则保持空白，禁止以示例值冒充史料。

- EV-ID：
- 关联 TOPIC / Q-ID / C-ID / EVENT-ID：
- 资料类型：原始档案 / 官修实录 / 私家文集 / 地方志 / 现代论文 / 二手转述 / 对话观点
- 题名、责任者、文献形成时间：
- 使用版本/底本/影印版次：
- 卷次、档号、页码、原始图像定位：
- 电子入口 URL（入口与具体条目 URL 分别记录）：
- 检索关键词、查询日期及可重现检索步骤：
- 原文短引及准确定位（版权合规）：
- 本人核对原文图像？是/否/无法访问：
- 日期：原文纪年／干支／历法／换算依据／精度：
- 直接记载了什么：
- 研究者由此推断了什么（单独列示）：
- 编纂者立场、时间差与可能遗漏：
- 与其他 EV-ID 的同源/转载关系：
- 支持、限制、反驳或无关的 C-ID：
- 可能的异文或史料冲突：
- 来源等级：原文核验 / 目录级 / 二手转述 / AI 推断 / 未核验
- 权利与公开引用边界：
- 审核者及审核记录：
- 下一步需要查什么：

**警戒**：《清实录》卷名和朝年不等于完成条目级核查；官修叙事、原始档案与后世研究的证据角色不可混同。
