# 方法论 M-001｜基础设施改革中的利益再分配、政治联盟与渐进制度变迁

> 适用范围：铁路、运河、公路、电网、电信、港口、能源与土地制度等改革史。此文是**分析流程**，不声称任何具体历史案例的隐秘动机已被证实。首次实例： [TOPIC-004 唐胥铁路](../../topics/late-qing-railway-political-economy/README.md)。

## 1. 研究对象与错误防护

不要把「新技术更有效率→反对者愚昧」或「反对者有损失→公开理由一定是伪装」写成结论。把技术收益、经济分配、政治否决权、文化信念、安全与主权顾虑、财政约束分为**相互独立、可以交互的解释变量**。事后最终成功，不等于最初行动者必然预见了成功，也不等于此前每一步都是既定战略。

**最重要的三层区分**：
1. 事实层：发生了什么、何时发生、路线如何、谁批准/反对？须有史料。
2. 机制层：利益如何改变？谁有权阻挠？通过什么程序？须能识别中间环节。
3. 动机层：当事人是否**有意识地**为了上述利益作选择？必须有更强的一手信件、会议记录、奏折或可信交叉证据。

## 2. 标准十步研究程序（可复制）

| 步骤 | 核查问题 | 最低交付物 |
|---|---|---|
| 01 记录原始说法 | 视频/文章每一条可以证伪的断言是什么？ | 逐条编号；标注转写、转述还是原文 |
| 02 还原时间线 | 提议、否决、批准、试运行、扩张是否属于不同年份？ | 事件—日期—行为者—原始出处表 |
| 03 还原空间网络 | 起终点、接驳点、地形、节点成本是什么？ | 旧/新线路及运输环节示意 |
| 04 分解技术经济学 | 建造与融资、单位运营成本、运力、转运成本、风险如何变化？ | 成本口径表；不得编造数量 |
| 05 绘制利益相关者 | 谁获得新收益、谁失去收入、谁只是改变就业？ | 逐主体收益/损失/证据表 |
| 06 识别权力与约束 | 谁审批、征地、持股、制定运价、承担政治责任？ | 否决权、产权、筹资和行政关系图 |
| 07 构造竞争性解释 | 技术可行性、财政、民生、地权、政治权力、观念各能解释什么？ | H1-Hn 假说和可反驳预测 |
| 08 验证动机与机制 | 当时文件是否明确表达了目标、联盟与条件交换？ | 区分同一时代旁证与本案直接证据 |
| 09 追踪动态反馈 | 试点是否改变运量、支持者、法律/政策与扩建意愿？ | 前后阶段的证据及反事实讨论 |
| 10 输出审计结果 | 哪些已核实、哪些只是理论上可能、哪些被证伪？ | Claims 台账、争议状态、下一轮材料清单 |

## 3. 博弈论与机制模型

对行动者 i 和政策方案 a，可作**定性会计框架**：

U_i(a) = E[净现金流_i(a)] + V_i[资产及控制权(a)] + P_i[政治收益(a)] - R_i[风险及责任(a)] - T_i[转换成本(a)]。

这只是分类式，不是可直接加总的实证估计式：货币、政治权力、风险效用单位不一致；比较大小须说明估值、权重、时间、折现率与不确定性。**不得填充没有来源的数字。**

区分五种关系：
- **替代**：新运力直接抢占旧路线运量。
- **互补**：短段铁路接驳船运，反而增加船舶运量。
- **分配**：总收益提高但旧主体可能绝对受损。
- **否决**：掌握许可/财政/征地权的一方能阻断整体有利的方案。
- **动态**：小规模试点改变技术认知、社会依赖与下一轮政治约束。

所谓「正和博弈」要有严格口径：总剩余增加不代表所有主体都受益；不能把**政治上可通过**等同于**帕累托改进**。有补偿方案也不等于补偿已实际兑现。「保护旧利益」可能是一种机制，也可能只是事后附会的故事。

## 4. 证据级别与标记

| 级别 | 材料类型 | 使用边界 |
|---|---|---|
| A | 经核对版本、日期与出处的一手档案或当事人原始文字 | 可支持其**说了/写了**什么；不自动证明其叙述真实或动机唯一 |
| B | 已阅读研究内容、可追踪注释的同行评议论文或专著 | 可作为学术解释及原始档案指针，直接引用时说明研究者观点 |
| C | 研究机构文章、可靠二手回顾、同期其他案例 | 可用于背景和旁证；不能冒充同一事件的直接证据 |
| D | 视频、口述转写、一般自媒体 | 只作为待验证主张入口 |
| T | 博弈论、经济学、制度变迁等形式理论 | 说明某机制可能成立；不构成某具体人物动机的史实证明 |

对每一条结论标示：**已确认事实 / 学术解释 / 可检验假说 / 未获支持 / 被证伪**；记录所依据的来源 ID 及未验证部分。多个 AI 重复同一材料不算独立验证。

## 5. 强制使用竞争性假说与反证

若研究「为何建运河而非完整铁路」，至少同时检验：
- H1 技术地形：部分地段无法修河，必须铁路接驳。**反证方向**：同一时期确有可行且便宜的全水路方案。
- H2 融资与工程风险：短铁路+河运优于一次性全铁路。**反证方向**：资本已充足、全线成本与风险更小。
- H3 既得利益安置：保留部分船运或转运收益以扩大支持联盟。**反证方向**：受益者不参与批准/实际损失更大；无联盟或交易证据。
- H4 产权/否决权：旗地、征地与清廷审批形成制度障碍。**反证方向**：相关权利人无否决能力且没有表达阻力。
- H5 观念、主权与安全风险：反对者真诚持有文化/政治顾虑。**反证方向**：当事人的同期文本或行动与声称理由明显冲突。

**关联不等于因果**：同一人反对铁路且投资车船业，只构成可查线索，仍需具体决策链条。区分「这群人可能受损」「这群人曾抗议」「他们影响了否决」「决策者为安抚他们而调整方案」四个证明门槛。

## 6. 资料搜索与停机规则

优先：官方档案馆/地方志/当年奏折、章程、地图、会计资料 → 有书目注释的专业论文 → 机构研究 → 自媒体。每条重要论点记录完整题名、作者、年份、可访问 URL/馆藏和实际阅读深度；**检索到摘要，不等于读了全文**。

搜索时交叉检索旧称、地名、年份、关键人物、行政文书和运输工程名称。发现年份或路线相互矛盾时，保留并列出处，不直接选择方便叙事的版本。

若缺少当事人动机证据，停止在「机制上可能」；若缺少原始成本数据，停止在「方向上可能」，不计算获利规模。每次更新标注「哪里不确定、影响何种结论、下一份所需资料」。
